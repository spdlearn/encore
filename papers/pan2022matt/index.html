Original Authors' Code / Protocol Root Cause

TWO AUTHOR FLAWS in CECNL/MAtt: (1) Training loop evaluates the test set after every epoch (1..300) and reports max_epoch(test_acc) (test-set peeking); (2) AttentionManifold computes unscaled bounded Log-Euclidean distances dLEM(Qi,Kj)d_{\text{LEM}}(Q_i, K_j)dLEM​(Qi​,Kj​) without a temperature τ\tauτ, causing softmax weights to collapse to uniform 1/P1/P1/P (entropy > 0.99).

Paper Abstract & Core Formulation

MAtt integrates spatial-temporal convolutional feature extraction with a Manifold Attention Module over temporal patch covariance matrices. Queries, keys, and values are projected on the SPD manifold via BiMap layers, pairwise attention energies are evaluated with the Log-Euclidean distance transformed by 1 / (1 + log(1 + d)), and value matrices are aggregated via the weighted Log-Euclidean Fréchet mean.

Deep-Dive Root-Cause Attribution (Original Authors' Code vs. Our Code), Failure Modes & Practitioner Guidance

Original Authors' Code / Protocol Root CauseTWO AUTHOR FLAWS in CECNL/MAtt: (1) Training loop evaluates the test set after every epoch (1..300) and reports max_epoch(test_acc) (test-set peeking); (2) AttentionManifold computes unscaled bounded Log-Euclidean distances dLEM(Qi,Kj)d_{\text{LEM}}(Q_i, K_j)dLEM​(Qi​,Kj​) without a temperature τ\tauτ, causing softmax weights to collapse to uniform 1/P1/P1/P (entropy > 0.99).
Our spd_learn Code / Harness Fix AppliedEvaluated MAtt under standardized 40-epoch CrossSession on Voyager: BNCI2014-001 reaches **64.43±14.0264.43 \pm 14.0264.43±14.02%** (final 64.04%, -10.28% below test-peeked 74.71%), BNCI2014-004 reaches 75.19±13.7175.19 \pm 13.7175.19±13.71%, and BNCI2015-001 reaches 73.47±12.6973.47 \pm 12.6973.47±12.69%.
Dataloader & Preprocessing DiffAuthors' scripts use per-epoch test-set selection and custom trial rejection on MAMEM-SSVEP-II and BCI-ERN; Voyager runs uncleaned MOABB splits.
Architecture & Optimizer Diffspd_learn vectorizes pairwise ∥log⁡(Qi)−log⁡(Kj)∥F\|\log(Q_i) - \log(K_j)\|_F∥log(Qi​)−log(Kj​)∥F​ in AttentionManifold and verifies that MAtt attention entropy exceeds 0.995 (indistinguishable from uniform averaging).
Where It Struggles / DivergesUniform attention collapse (H/log(P) > 0.99) makes MAtt's Q/K/V projections redundant (SPDMetaFormer achieves the exact same 64.04% with fixed 1/P averaging).
Primary Mathematical Failure ModeBecause 1 / (1 + log(1 + d)) maps all non-negative geodesic distances into (0, 1] without a learnable temperature parameter, softmax(sim) cannot produce sharp attention weights.
Silent Diagnostic RiskAblation studies attributing MAtt's accuracy gains to selective temporal attention can be confounded by the spatial-temporal Conv2d frontend and uniform tangent averaging across patches.
Practitioner RecommendationReplace the static 1/(1 + log(1 + d)) similarity with temperature-scaled negative geodesic distance (as in SymSPDAttention) or a lightweight depthwise token mixer (as in SPDMetaFormer).
