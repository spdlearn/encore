Deep-Dive Gap Analysis, Failure Modes & Practitioner Guidance

Dataloader & Preprocessing DiffOn MAMEM-SSVEP-II and BCI-ERN, original scripts use custom trial-rejection and subject-specific epoch windows; spd-bench uses uncleaned MOABB continuous epochs with trace-regularized patch covariances (ϵ=10−4\epsilon = 10^{-4}ϵ=10−4).
Architecture & Optimizer Diffspd_learn implements Log-Euclidean metric attention (AttentionManifold) with vectorized pairwise ∥log(Qi)−log(Kj)∥F\|log(Q_i) - log(K_j)\|_{F}∥log(Qi​)−log(Kj​)∥F​ distances and SPDBatchNormMean.
Where It Struggles / DivergesAttention weights collapse toward uniform 1/P (entropy H/log(P) > 0.99) when temporal patch count P > 6 because bounded pairwise Log-Euclidean distances lack a learnable temperature scale.
Primary Mathematical Failure ModeBecause 1 / (1 + log(1 + d)) maps all non-negative geodesic distances into (0, 1] without a learnable temperature parameter, softmax(sim) cannot produce sharp attention weights.
Silent Diagnostic RiskAblation studies attributing MAtt's accuracy gains to selective temporal attention can be confounded by the spatial-temporal Conv2d frontend and uniform tangent averaging across patches.
Practitioner RecommendationReplace the static 1/(1 + log(1 + d)) similarity with temperature-scaled negative geodesic distance (as in SymSPDAttention) or a lightweight depthwise token mixer (as in SPDMetaFormer).

def verify_pan2022matt() -> dict[str, dict[str, Any]]:
    from spd_learn.functional import log_euclidean_distance
    from spd_learn.models import AttentionManifold, MAtt

    # Claim 1: Structural (AttentionManifold preserves SPD structure across patch sequences)
    X_seq = make_spd((4, 4), 10, cond=12.0, dtype=torch.float32)
    att = AttentionManifold(in_features=10, out_features=8).eval()
    with torch.no_grad():
        Y_seq = att(X_seq)
        min_eig = float(torch.linalg.eigvalsh(Y_seq).min().item())

        # Claim 2: Signal (1/(1+log(1+d)) softmax entropy collapse to >0.99 uniform mixing)
        Q = att.q_trans(X_seq)
        K = att.k_trans(X_seq)
        d_le = log_euclidean_distance(Q.unsqueeze(2), K.unsqueeze(1))
        sim = 1.0 / (1.0 + torch.log1p(d_le))
        probs = F.softmax(sim, dim=-2)
        norm_entropy = float(
            (-(probs * torch.log(probs + 1e-12)).sum(dim=-2) / math.log(4)).mean().item()
        )

    # Claim 3: Analytical (Real BNCI2014-001 cross-session evaluation)
    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=12, decim=3)
    model = MAtt(
        n_chans=12,
        n_outputs=4,
        n_patches=2,
        temporal_out_channels=10,
        attention_in_features=10,
        attention_out_features=8,
    )
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "pan2022matt_c1": {
            "output_shape": list(Y_seq.shape),

            "normalized_attention_entropy": round(norm_entropy, 5),

            "passed": norm_entropy > 0.99,
            "scope": "full",
