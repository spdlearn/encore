Manifold Self-Attention Preserves SPD Structure Across Temporal Patches Despite Bounded Softmax Compression

Paper: MAtt: A Manifold Attention Network for EEG Decoding (NeurIPS 2022) · Authors: Yue-Ting Pan, Jing-Lun Chou, Chun-Shu Wei · Geometry: Log-Euclidean Geodesic Distance Attention 1/(1 + log(1 + d_LEM(Q_i, K_j))) & Tangent Aggregation

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: main (spd_learn.models.MAtt)

Closed-Loop Empirical Audit & MOABB / spd-bench Harness Comparison

Can token-to-token self-attention operate directly on sequences of temporal EEG covariance matrices while respecting SPD manifold geometry? To test whether Log-Euclidean manifold attention improves spatiotemporal EEG decoding, we audit MAtt and AttentionManifold across synthetic SPD sequences and cross-session BNCI2014-001 recordings. First, AttentionManifold(10, 8) maps sequences of 10x10 SPD patch covariances to 8x8 SPD outputs with minimum eigenvalue 0.607 > 0 (Panel A, Claim C1). Second, inspecting the attention probability matrix reveals that the bounded similarity kernel 1 / (1 + log(1 + d_LEM)) compresses pre-softmax logits into (0, 1], resulting in normalized attention entropy 0.99996 and maximum weight deviation 0.0078 from uniform averaging (Panel B, Claim C2). Third, across our 9-subject MOABB BNCI2014-001 harness, MAtt achieves 72.90 +/- 12.40% (vs. 74.68 +/- 11.80% published, delta -1.78%) and 69.79% on Subject 3 Session E (Panel C, Claim C3). Overall, these results confirm that MAtt provides a competitive convolutional-SPD backbone whose attention selectivity is bottlenecked by unscaled bounded similarity.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Vaswani et al. (2017) compute scaled dot-product attention over Euclidean vectors; whereas Euclidean transformers flatten spatial structure, MAtt holds the Q/K/V protocol fixed on S++^d using BiMap projections and Log-Euclidean tangent aggregation.
Primary Failure ModeBecause 1 / (1 + log(1 + d)) maps all non-negative geodesic distances into (0, 1] without a learnable temperature parameter, softmax(sim) cannot produce sharp attention weights.
Silent Diagnostic RiskAblation studies attributing MAtt's accuracy gains to selective temporal attention can be confounded by the spatial-temporal Conv2d frontend and uniform tangent averaging across patches.
Practitioner RecommendationReplace the static 1/(1 + log(1 + d)) similarity with temperature-scaled negative geodesic distance (as in SymSPDAttention) or a lightweight depthwise token mixer (as in SPDMetaFormer).

def verify_pan2022matt() -> dict[str, dict[str, Any]]:
    from spd_learn.functional import log_euclidean_distance
    from spd_learn.models import AttentionManifold, MAtt

    # Claim 1: Structural (AttentionManifold preserves SPD structure across patch sequences)
    X_seq = make_spd((4, 4), 10, cond=12.0, dtype=torch.float32)
    att = AttentionManifold(in_features=10, out_features=8).eval()
    with torch.no_grad():
        Y_seq = att(X_seq)
        min_eig = float(torch.linalg.eigvalsh(Y_seq).min().item())

        # Claim 2: Signal (1/(1+log(1+d)) softmax entropy collapse to >0.99 uniform mixing)
        Q = att.q_trans(X_seq)
        K = att.k_trans(X_seq)
        d_le = log_euclidean_distance(Q.unsqueeze(2), K.unsqueeze(1))
        sim = 1.0 / (1.0 + torch.log1p(d_le))
        probs = F.softmax(sim, dim=-2)
        norm_entropy = float(
            (-(probs * torch.log(probs + 1e-12)).sum(dim=-2) / math.log(4)).mean().item()
        )

    # Claim 3: Analytical (Real BNCI2014-001 cross-session evaluation)
    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=12, decim=3)
    model = MAtt(
        n_chans=12,
        n_outputs=4,
        n_patches=2,
        temporal_out_channels=10,
        attention_in_features=10,
        attention_out_features=8,
    )
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "pan2022matt_c1": {
            "output_shape": list(Y_seq.shape),
            "min_eig_output": min_eig,
            "passed": min_eig > 0.0 and list(Y_seq.shape) == [4, 4, 8, 8],
            "scope": "full",
        },

Paper Abstract

MAtt integrates spatial-temporal convolutional feature extraction with a Manifold Attention Module over temporal patch covariance matrices. Queries, keys, and values are projected on the SPD manifold via BiMap layers, pairwise attention energies are evaluated with the Log-Euclidean distance transformed by 1 / (1 + log(1 + d)), and value matrices are aggregated via the weighted Log-Euclidean Fréchet mean.
