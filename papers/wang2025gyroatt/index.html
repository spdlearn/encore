Temperature-Scaled Lie-Algebraic Attention Restores Token Selectivity Lost by Bounded Geodesic Kernels

Paper: Towards a General Attention Framework on Gyrovector Spaces for Matrix Manifolds (NeurIPS 2025) · Authors: Rui Wang, Chen Hu, Xiaoning Song, Xiao-Jun Wu, Nicu Sebe, Ziheng Chen · Geometry: SPD Gyrovector Space (Mobius Addition/Scalar Mult) & Lie-Algebraic SymSPDAttention

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: PR #55 (feat/pr-d-manifold-attention-transformers)

All Paper Datasets: Closed-Loop spd-bench & MOABB Harness Audit (3 Datasets)

Can gyrovector and Lie-algebraic self-attention on $\mathcal{S}_{++}^{d}$ overcome the uniform-entropy saturation of MAtt's bounded similarity kernel? To test whether learnable temperature scaling in SymSPDAttention sharpens token selectivity while preserving positive definiteness, we audit GyroSPDAttention, SymSPDAttention, and GyroSPDAtt. First, both GyroSPDAttention and SymSPDAttention output strictly positive definite matrices across patch sequences (minimum eigenvalues 0.578 and 0.568 > 0; Panel A, Claim C1). Second, whereas MAtt's bounded kernel 1/(1 + log(1 + d)) traps normalized attention entropy at 0.968, SymSPDAttention's temperature-scaled softmax(-exp(s) * D) reduces normalized entropy to 0.0017 (Panel B, Claim C2). Third, on real cross-session BNCI2014-001, GyroSPDAtt reaches 73.26% on Subject 3 and $74.40 \pm 11.50$% across 9 subjects (vs. $75.62 \pm 11.10$% published; Panel C, Claim C3). Overall, these results confirm that unbounded temperature-scaled geodesic logits restore selective temporal attention on SPD manifolds.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Pan et al. (2022) weight Log-Euclidean tangent values via softmax(1 / (1 + log(1 + d))); whereas MAtt compresses all distances into (0, 1], SymSPDAttention applies softmax(-exp(s) * d) with a learnable log-temperature s.
Primary Failure ModeIntrinsic GyroSPDAttention requires repeated matrix square roots and powers inside Mobius addition loops, increasing forward/backward latency relative to Lie-algebraic SymSPDAttention.
Silent Diagnostic RiskAllowing log-scale s to grow unboundedly (> 4.0) collapses softmax weights onto a single patch token and causes vanishing gradients for non-selected patches.
Practitioner RecommendationPrefer attention_type='sym' (SymSPDAttention) for fast tangent-space aggregation and clamp log_scale within [-3.0, 3.0].

Paper Abstract

We introduce a general attention framework on gyrovector spaces for matrix manifolds (GyroAtt). On SPD manifolds, GyroSPDAttention transforms queries, keys, and values via orthogonal gyro-automorphisms parameterized by Cayley maps, aggregates values via gyro-barycenters, and applies left gyro-translation biases, while SymSPDAttention performs intrinsic SPDLinear projections in tangent space.
