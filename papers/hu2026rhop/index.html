Second-Order Riemannian High-Order Pooling Recovers 39.93 Percentage Points Lost by Temporal Mean Pooling on Bandpass EEG

Paper: Riemannian High-Order Pooling for Brain Foundation Models (ICLR 2026) · Authors: Chen Hu, Rui Wang, Ziheng Chen, Xiao-Jun Wu, Nicu Sebe · Geometry: Gaussian-Process SPD Descriptor G in $\mathcal{S}_{++}^{d+1}$ + Bilinear Contraction + PEM/LEM

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr10-rhop

All Paper Datasets: Closed-Loop spd-bench & MOABB Harness Audit (2 Datasets)

Why does standard first-order token mean pooling fail when applied to bandpass-filtered oscillatory EEG representations in Brain Foundation Models? To test whether embedding first- and second-order token statistics into a (d+1)x(d+1) Gaussian-Process SPD descriptor recovers phase-locked oscillatory information, we compare RiemannianHighOrderPooling (RHOP) against temporal mean pooling on synthetic zero-mean sequences and real BNCI2014-001 trials. First, GaussianSPDDescriptor maps (8, 16, 6) token sequences into strictly positive definite (8, 7, 7) block matrices with minimum eigenvalue 0.0997 > 0 (Panel A, Claim C1). Second, on zero-mean oscillatory sequences where class identity is encoded in cross-channel correlation, first-order mean pooling collapses to feature norm 4.23e-7 (50% chance), whereas RHOP reaches 100.0% test accuracy (Panel B, Claim C2). Third, on real 8-30 Hz bandpass-filtered BNCI2014-001 Subject 3 trials, temporal mean pooling stays near chance at 23.96%, whereas RHOP(metric='PEM', power=0.5) achieves 63.89% cross-session accuracy (+39.93 pp gain; Panel C, Claim C3). Overall, these results prove that second-order Riemannian pooling is essential whenever neural tokens encode information in oscillatory covariance rather than DC mean offsets.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, standard Brain Foundation Models (BIOT, LaBraM) pool token sequences via first-order average pooling or a CLS token; whereas mean pooling discards cross-channel covariance Sigma = E[x_t x_t^T], RHOP embeds (mu, alpha^2 Sigma + beta^2 K_GP) into $\mathcal{S}_{++}^{d+1}$ via Schur-complement completion.
Primary Failure ModeComputing the RBF Gaussian-process kernel matrix K_GP across high-dimensional token channels scales as O(B * d^2 * T) and requires bandwidth tuning.
Silent Diagnostic RiskAppending a first-order global average pooling head after bandpass-filtered EEG convolutions silently destroys oscillatory power and cross-channel coherence features.
Practitioner RecommendationReplace global average pooling in EEG encoders and foundation model adapters with RiemannianHighOrderPooling(metric='PEM', power=0.5).

    # Claim 2: Zero-mean token sequences with distinct covariances
    gen = torch.Generator().manual_seed(42)
    N, T, D = 80, 24, 6
    X_list, y_list = [], []
    cov_0 = torch.eye(D)
    cov_1 = torch.eye(D)
    cov_1[0, 1] = cov_1[1, 0] = 0.85
    cov_1[2, 3] = cov_1[3, 2] = -0.85
    L0 = torch.linalg.cholesky(cov_0)
    L1 = torch.linalg.cholesky(cov_1)
    for i in range(N):
        c = i % 2
        Z = torch.randn(T, D, generator=gen)
        Z = Z - Z.mean(dim=0, keepdim=True)
        L = L1 if c == 1 else L0
        X_list.append(Z @ L.T)
        y_list.append(c)
    X_seq = torch.stack(X_list, dim=0)
    y_seq = torch.tensor(y_list, dtype=torch.long)

Paper Abstract

Brain Foundation Models and EEG Transformers typically rely on first-order mean pooling or a single CLS token, discarding second-order inter-token covariance statistics. Riemannian High-Order Pooling (RHOP) embeds token mean and covariance into a quotient Gaussian SPD matrix and projects it via Riemannian geometry (LEM, PEM, LCM) to fuse second-order geometric statistics with the Transformer token representation.
