Riemannian Autoencoding and Stiefel k-NN Graph Convolution Regularize Cross-Session EEG Decoding

Paper: SPDNet-AE: a Compact SPD Representation through Riemannian Autoencoding & Stiefel-SPD Manifold Graph Convolution (HAL 2026 / IEEE TNSRE 2026) · Authors: Charlotte Boucherie, Thibault de Surrel, Florian Yger · Geometry: Stiefel Dimension-Expanding SPD Decoder + Stiefel k-NN Tangent Graph Convolution

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr15-spdnet-ae-ssgcnet

Closed-Loop Empirical Audit & MOABB / spd-bench Harness Comparison

Can unsupervised Riemannian autoencoding on S++^d (SPDNet-AE) and dynamic k-NN graph convolution over Stiefel-projected patch covariances (SSGCNet) regularize cross-session EEG classification? To test whether dimension-expanding SPD decoders and tangent-space k-NN graph aggregation preserve manifold invariants and decode real EEG, we audit SPDNetAE and SSGCNet on BNCI2014-001. First, SPDNetAE compresses 22x22 EEG covariances into a 10x10 SPD bottleneck (minimum eigenvalue 0.123 > 0) and reconstructs 22x22 SPD matrices (minimum eigenvalue 0.123 > 0; Panel A, Claim C1). Second, 12 steps of unsupervised optimization monotonically reduce the Log-Euclidean geodesic reconstruction loss ||log(S_in) - log(S_rec)||_F^2 on real Subject 3 covariances from 65.18 down to 40.52 (Panel B, Claim C2). Third, on real BNCI2014-001 Subject 3 cross-session transfer, SPDNetAE achieves 67.01% test accuracy and SSGCNet achieves 68.40% (Panel C, Claim C3). Overall, these results confirm that geodesic reconstruction bottlenecks and dynamic k-NN tangent graphs learn transferable representations on S++^d.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, standard SPDNet applies only dimension-contracting BiMap layers for supervised classification; whereas contracting W X W^T cannot reconstruct a higher-dimensional ambient covariance matrix, SPDNet-AE uses BiMapIncreaseDim padding + Stiefel rotation + ReEig to decode back to S++^C.
Primary Failure ModeExpanding a rank-k latent matrix Z in S++^k to ambient dimension C > k produces C - k zero eigenvalues before ReEig clamping, so the reconstructed matrix lies on the boundary of the cone up to the epsilon floor.
Silent Diagnostic RiskMeasuring reconstruction loss with AIRM distance rather than Log-Euclidean distance heavily penalizes the epsilon-floored orthogonal complement dimensions.
Practitioner RecommendationTrain SPDNet-AE with Log-Euclidean reconstruction loss ||log(S_in) - log(S_rec)||_F^2 and reuse BiMap(in_features, out_features) + ReEig(eps) directly as the decoder block.

def verify_boucherie2026spdnetae_ssgcnet() -> dict[str, dict[str, Any]]:
    from spd_learn.models import SPDNetAE, SSGCNet

    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=22, decim=3)
    ae = SPDNetAE(n_chans=22, n_outputs=4, encoder_dims=(16, 10))
    Z_lat = ae.encode(X_tr[:8])
    S_rec = ae.decode(Z_lat)
    min_eig_lat = float(torch.linalg.eigvalsh(Z_lat).min().item())
    min_eig_rec = float(torch.linalg.eigvalsh(S_rec).min().item())

    opt = torch.optim.Adam(ae.parameters(), lr=1e-2)
    S0 = ae.cov_frontend(X_tr[:16]).detach()
    R0 = ae.autoencode(X_tr[:16])
    loss_init = float(ae.reconstruction_loss(S0, R0).item())
    for _ in range(12):
        opt.zero_grad()
        Ri = ae.autoencode(X_tr[:16])
        l = ae.reconstruction_loss(S0, Ri)
        l.backward()
        opt.step()
    R_end = ae.autoencode(X_tr[:16])
    loss_final = float(ae.reconstruction_loss(S0, R_end).item())

    ae_cls = SPDNetAE(n_chans=22, n_outputs=4, encoder_dims=(16, 12))
    ssgc_cls = SSGCNet(
        n_chans=22, n_outputs=4, n_nodes=2, temporal_filters=10, stiefel_dim=8, k_neighbors=1
    )
    res_ae = train_and_eval_bnci_classifier(ae_cls, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)
    res_ssgc = train_and_eval_bnci_classifier(ssgc_cls, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "boucherie2026spdnetae_ssgcnet_c1": {
            "latent_min_eig": min_eig_lat,
            "reconstructed_min_eig": min_eig_rec,
            "passed": min_eig_lat > 0.0 and min_eig_rec > 0.0,
            "scope": "full",
        },
        "boucherie2026spdnetae_ssgcnet_c2": {
            "initial_geodesic_recon_loss": loss_init,
            "final_geodesic_recon_loss": loss_final,
            "passed": loss_final < loss_init,
            "scope": "full",
        },

Paper Abstract

SPDNet-AE learns compact low-dimensional SPD representations via an SPDNet encoder and transposed bilinear congruence decoder trained with Riemannian geodesic reconstruction loss, strictly preserving positive definiteness unlike Euclidean autoencoders. SSGCNet performs tangent-space k-nearest-neighbor graph attention aggregation over Stiefel-reduced patch covariances.
