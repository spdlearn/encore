Paper Overview & Mathematical Spec SPDNet-AE: a Compact SPD Representation through Riemannian Autoencoding & Stiefel-SPD Manifold Graph Convolution (SSGCNet) (ESANN 2026 (HAL-05600912v1) / IEEE TNSRE 2026) 3 Figures · 2 Paper Tables · 2 Voyager Benchmarks
Paper Abstract & Core Formulation

SPDNet-AE learns compact low-dimensional SPD representations via an SPDNet encoder and transposed bilinear congruence decoder trained with Riemannian geodesic reconstruction loss, strictly preserving positive definiteness unlike Euclidean autoencoders. SSGCNet performs tangent-space k-nearest-neighbor graph attention aggregation over Stiefel-reduced patch covariances.

/ponytail Primitive Reuse & Engineering Notes
  • Replaced 68 lines of manual Stiefel parametrization and identity-padding in SPDDecoderBlock with direct delegation to BiMap(in_features, out_features) + ReEig(threshold=eps).

Primary Mathematical Failure ModeExpanding a rank-k latent matrix Z in S++k\mathcal{S}_{++}^{k}S++k​ to ambient dimension C > k produces C - k zero eigenvalues before ReEig clamping, so the reconstructed matrix lies on the boundary of the cone up to the epsilon floor.

def verify_boucherie2026spdnetae_ssgcnet() -> dict[str, dict[str, Any]]:
    from spd_learn.models import SPDNetAE, SSGCNet

    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=22, decim=3)
    ae = SPDNetAE(n_chans=22, n_outputs=4, bimap_dims=(16, 10))
    Z_lat = ae.encode(X_tr[:8])
    S_rec = ae.decode(Z_lat)
    min_eig_lat = float(torch.linalg.eigvalsh(Z_lat).min().item())
    min_eig_rec = float(torch.linalg.eigvalsh(S_rec).min().item())

    opt = torch.optim.Adam(ae.parameters(), lr=1e-2)
    S0 = ae.cov_frontend(X_tr[:16]).detach()
    R0 = ae.autoencode(X_tr[:16])
    loss_init = float(ae.reconstruction_loss(S0, R0).item())
    for _ in range(12):
        opt.zero_grad()
        Ri = ae.autoencode(X_tr[:16])
        l = ae.reconstruction_loss(S0, Ri)
        l.backward()
        opt.step()
    R_end = ae.autoencode(X_tr[:16])
    loss_final = float(ae.reconstruction_loss(S0, R_end).item())

    ae_cls = SPDNetAE(n_chans=22, n_outputs=4, bimap_dims=(16, 12))
    ssgc_cls = SSGCNet(
        n_chans=22, n_outputs=4, n_nodes=2, temporal_filters=10, stiefel_dim=8, k_neighbors=1
    )
    res_ae = train_and_eval_bnci_classifier(ae_cls, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)
    res_ssgc = train_and_eval_bnci_classifier(ssgc_cls, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "boucherie2026spdnetae_ssgcnet_c1": {
            "latent_min_eig": min_eig_lat,
            "reconstructed_min_eig": min_eig_rec,
            "passed": min_eig_lat > 0.0 and min_eig_rec > 0.0,
            "scope": "full",
        },
        "boucherie2026spdnetae_ssgcnet_c2": {
            "initial_geodesic_recon_loss": loss_init,
            "final_geodesic_recon_loss": loss_final,
            "passed": loss_final < loss_init,
            "scope": "full",
        },
        "boucherie2026spdnetae_ssgcnet_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "spdnetae_bnci_subj3_test_acc_pct": res_ae["test_acc_pct"],
