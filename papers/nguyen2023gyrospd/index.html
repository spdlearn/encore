Gyrovector Left-Translation Equips Stiefel Bilinear Layers with an Intrinsic Manifold Bias

Paper: Building Neural Networks on Matrix Manifolds: A Gyrovector Space Approach (ICML 2023) · Authors: Xuan Son Nguyen, Shuo Yang · Geometry: AIRM Gyrovector Space (Mobius Gyro-Translation B^{1/2} W X W^T B^{1/2})

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr14-spdresnet-gyrospd

Closed-Loop Empirical Audit & MOABB / spd-bench Harness Comparison

Why do standard SPDNet BiMap layers lack an additive bias term, and how can an intrinsic manifold translation be applied after Stiefel congruence? To test whether Mobius gyro-translation B (+) (W X W^T) = B^{1/2} (W X W^T) B^{1/2} shifts SPD representations while preserving cone closure, we audit GyroSPDLayer and GyroSPD. First, GyroSPDLayer(6, 4) maps 6x6 SPD matrices into 4x4 SPD matrices with minimum eigenvalue 0.355 > 0 (Panel A, Claim C1). Second, setting the SPD gyro-bias to B = 10 I increases the mean output trace from 8.03 (unbiased orthogonal projection bound) to 55.43, proving non-trivial manifold translation (Panel B, Claim C2). Third, on real BNCI2014-001 Subject 3 cross-session transfer, GyroSPD achieves 55.21% test accuracy (vs. 25.0% chance; Panel C, Claim C3). Overall, these results show that gyrovector translation provides a mathematically grounded bias operation on S++^d that is algebraically equivalent to SPD batchnorm rebiasing.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Huang and Van Gool (2017) restrict hidden layers to linear congruence W X W^T; whereas BiMap cannot translate the manifold origin, GyroSPDLayer applies left gyro-translation B^{1/2} (W X W^T) B^{1/2}, which we implement in 1 line by reusing spd_rebiasing.
Primary Failure ModeWhen GyroSPDLayer is immediately followed by SPDBatchNormMean, the batchnorm centering step cancels out the preceding gyro-translation bias.
Silent Diagnostic RiskAdding both a GyroSPDLayer bias B and an SPDBatchNormMean bias on the same layer introduces redundant SPD parameters.
Practitioner RecommendationUse GyroSPDLayer in batchnorm-free SPD networks, or rely on SPDBatchNormMean's built-in rebiasing when batch normalization is active.

Executable Verifier Source Code (repro/trackio_runner.py)

def verify_nguyen2023gyrospd() -> dict[str, dict[str, Any]]:
    from spd_learn.models import GyroSPD, GyroSPDLayer

    X = make_spd((6,), 6, cond=10.0, dtype=torch.float32)
    layer = GyroSPDLayer(in_features=6, out_features=4)
    out = layer(X)
    min_eig = float(torch.linalg.eigvalsh(out).min().item())

    with torch.no_grad():
        layer.bias = 10.0 * torch.eye(4)
        out_scaled = layer(X)
        trace_in = float(torch.diagonal(X, dim1=-2, dim2=-1).sum(dim=-1).mean().item())
        trace_out = float(torch.diagonal(out_scaled, dim1=-2, dim2=-1).sum(dim=-1).mean().item())

    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=12, decim=3)
    model = GyroSPD(n_chans=12, n_outputs=4, bimap_dims=(12, 12))
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=1e-2)

    return {
        "nguyen2023gyrospd_c1": {
            "min_eig_output": min_eig,
            "passed": min_eig > 0.0,
            "scope": "full",
        },
        "nguyen2023gyrospd_c2": {
            "input_trace": trace_in,
            "gyro_translated_trace": trace_out,
            "passed": trace_out > trace_in,
            "scope": "full",
        },
        "nguyen2023gyrospd_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "bnci_subj3_train_acc_pct": res["train_acc_pct"],
            "bnci_subj3_test_acc_pct": res["test_acc_pct"],
            "chance_level_pct": 25.0,
            "passed": res["test_acc_pct"] >= 50.0,
            "scope": "full",
        },
    }

Paper Abstract

GyroSPD constructs deep neural networks on SPD manifolds using gyrovector space operations, combining bilinear Stiefel projections with left gyro-translation biases parameterized on the SPD manifold.
