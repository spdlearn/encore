Paper Abstract & Core Formulation

GyroSPD constructs deep neural networks on SPD manifolds using gyrovector space operations, combining bilinear Stiefel projections with left gyro-translation biases parameterized on the SPD manifold.

Deep-Dive Gap Analysis, Failure Modes & Practitioner Guidance

Dataloader & Preprocessing DiffPaper evaluates HDM05 and Radar with custom gyro-calculus scripts; spd-bench evaluates HDM05, Radar, and MOABB BNCI2014-001 under unified holdout/CrossSession splits.
Architecture & Optimizer Diffspd_learn implements GyroSPDLayer combining BiMap rotation WXW⊤W X W^\topWXW⊤ with SPD gyro-translation P ⊕ B = P^{1/2} B P^{1/2} parameterized via tangent matrix exp.
Where It Struggles / DivergesUnconstrained gyro-bias B scales output trace multiplicatively (Tr(P ⊕ αI) = α Tr(P)), requiring unit-determinant or trace-normalized bias constraints in deep stacks.
Primary Mathematical Failure ModeWhen GyroSPDLayer is immediately followed by SPDBatchNormMean, the batchnorm centering step cancels out the preceding gyro-translation bias.
Silent Diagnostic RiskAdding both a GyroSPDLayer bias B and an SPDBatchNormMean bias on the same layer introduces redundant SPD parameters.
Practitioner RecommendationUse GyroSPDLayer in batchnorm-free SPD networks, or rely on SPDBatchNormMean's built-in rebiasing when batch normalization is active.

def verify_nguyen2023gyrospd() -> dict[str, dict[str, Any]]:
    from spd_learn.models import GyroSPD, GyroSPDLayer

    X = make_spd((6,), 6, cond=10.0, dtype=torch.float32)
    layer = GyroSPDLayer(in_features=6, out_features=4)
    out = layer(X)
    min_eig = float(torch.linalg.eigvalsh(out).min().item())

    with torch.no_grad():
        layer.bias = 10.0 * torch.eye(4)
        out_scaled = layer(X)
        trace_in = float(torch.diagonal(X, dim1=-2, dim2=-1).sum(dim=-1).mean().item())
        trace_out = float(torch.diagonal(out_scaled, dim1=-2, dim2=-1).sum(dim=-1).mean().item())

    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=12, decim=3)
    model = GyroSPD(n_chans=12, n_outputs=4, bimap_dims=(12, 12))
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=1e-2)
