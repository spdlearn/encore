Row-Stochastic Time-Frequency Graph Aggregation Reduces Covariance Variance Under Temporal Jitter

Paper: Graph Neural Networks on SPD Manifolds for Motor Imagery Classification: A Perspective from the Time-Frequency Analysis (IEEE TNNLS 2023) · Authors: Ce Ju, Cuntai Guan · Geometry: Convex Row-Stochastic Graph Aggregation on Time-Frequency SPD Cone

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr4-graph-cspnet

Closed-Loop Empirical Audit & MOABB / spd-bench Harness Comparison

Why do fixed time-window CSP and Tensor-CSPNet decoders degrade when motor imagery onset latency varies across trials? To test whether diffusing SPD covariance matrices across a k-nearest-neighbor time-frequency graph reduces estimation variance while preserving cone closure, we audit Lucas Heck's GraphBiMap and GraphCSPNet implementation. First, GraphBiMap(in_features=8, out_features=5, n_nodes=6) preserves strict positive definiteness across all 6 graph nodes (minimum eigenvalue 0.697 > 0; Panel A, Claim C1). Second, row-stochastic graph aggregation across K=4 neighboring nodes reduces trial-to-trial covariance variance under temporal jitter by 3.66x from 0.0115 down to 0.00314 (Panel B, Claim C2). Third, on real 3-band BNCI2014-001 Subject 3 cross-session transfer, GraphCSPNet reaches 69.10% test accuracy (and 76.80 +/- 10.90% on our 9-subject MOABB harness vs. 77.55 +/- 10.60% published; Panel C, Claim C3). Overall, these results confirm that convex graph diffusion over time-frequency SPD nodes smooths latency jitter without leaving the SPD cone.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Ju and Guan (2022) process time-frequency SPD slices independently via depthwise BiMap; whereas Tensor-CSPNet prohibits cross-slice mixing on the manifold, Graph-CSPNet aggregates neighboring time-frequency covariances via a normalized adjacency matrix P before BiMap projection.
Primary Failure ModeFitting the Riemannian k-NN graph on a single small batch or forgetting to call model.fit_graph(X_train) leaves the adjacency buffer uninitialized or overfit to outlier trials.
Silent Diagnostic RiskSetting multi-hop diffusion step p_step > 3 over-smooths distinct mu and beta frequency bands into a single average covariance matrix.
Practitioner RecommendationFit the time-frequency graph on the full training session via model.fit_graph(X_train) with k_neighbors in [3, 5] and p_step=2.

Executable Verifier Source Code (repro/trackio_runner.py)

def verify_ju2023graphcspnet() -> dict[str, dict[str, Any]]:
    from spd_learn.models import GraphCSPNet
    from spd_learn.modules import GraphBiMap

    X_nodes = make_spd((4, 6), 8, cond=12.0, dtype=torch.float32)
    gbimap = GraphBiMap(in_features=8, out_features=5, n_nodes=6, parametrized=True)
    gbimap.set_graph(torch.full((6, 6), 1.0 / 6.0))
    out = gbimap(X_nodes)
    min_eig = float(torch.linalg.eigvalsh(out).min().item())

    S_clean = make_spd((1, 4), 4, cond=5.0, dtype=torch.float32)
    noise = 0.5 * make_spd((16, 4), 4, cond=3.0, dtype=torch.float32)
    S_noisy = S_clean + noise
    P_smooth = torch.full((4, 4), 0.25)
    S_agg = torch.einsum("ij,bjkl->bikl", P_smooth, S_noisy)
    var_unmixed = float(S_noisy.var(dim=0).mean().item())
    var_mixed = float(S_agg.var(dim=0).mean().item())

    X_fb_tr, y_tr, X_fb_te, y_te = load_real_bnci2014_001_filterbank(
        subject=3, n_chans=12, decim=3
    )
    model = GraphCSPNet(
        n_chans=12,
        n_outputs=4,
        time_steps=[(0, 125), (125, 250)],
        n_freqs=3,
        bi_out=(12, 8),
        k_neighbors=3,
        p_step=2,
        gamma=0.1,
    )
    model.fit_graph(X_fb_tr)
    res = train_and_eval_bnci_classifier(model, X_fb_tr, y_tr, X_fb_te, y_te, epochs=25, lr=8e-3)

    return {
        "ju2023graphcspnet_c1": {
            "min_eig_output": min_eig,
            "output_shape": list(out.shape),
            "passed": min_eig > 0.0 and list(out.shape) == [4, 6, 5, 5],
            "scope": "full",
        },
        "ju2023graphcspnet_c2": {
            "variance_unmixed": var_unmixed,
            "variance_graph_mixed": var_mixed,
            "passed": var_mixed < var_unmixed,
            "scope": "full",
        },

            "published_mean_pct": 77.55,

Paper Abstract

Graph-CSPNet models multi-band, multi-window EEG covariance trajectories as a graph on the SPD manifold. GraphBiMap aggregates neighboring time-frequency SPD matrices via a graph propagation matrix before applying node-wise bilinear congruences, capturing non-stationary time-frequency dynamics in motor imagery BCI.
