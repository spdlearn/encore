Deep-Dive Gap Analysis, Failure Modes & Practitioner Guidance

Dataloader & Preprocessing DiffPaper constructs a dense 9-band × 4-window (36-node) time-frequency SPD graph with pre-computed Laplacian diffusion; our Voyager MOABB harness uses a 6-node time-frequency graph with normalized adjacency diffusion.
Architecture & Optimizer Diffspd_learn implements GraphBiMap (`M_i = Σ_j A_ij W_j X_j W_j^T`) with positive row-normalized adjacency weights to guarantee cone closure without manual eigenvalue projection.
Where It Struggles / DivergesOver-smoothing across time-frequency graph neighbors (degree K ≥ 4) blurs transient motor-onset covariance spikes on rapid-response subjects.
Primary Mathematical Failure ModeFitting the Riemannian k-NN graph on a single small batch or forgetting to call model.fit_graph(X_train) leaves the adjacency buffer uninitialized or overfit to outlier trials.
Silent Diagnostic RiskSetting multi-hop diffusion step p_step > 3 over-smooths distinct mu and beta frequency bands into a single average covariance matrix.
Practitioner RecommendationFit the time-frequency graph on the full training session via model.fit_graph(X_train) with k_neighbors in [3, 5] and p_step=2.

def verify_ju2023graphcspnet() -> dict[str, dict[str, Any]]:
    from spd_learn.models import GraphCSPNet
    from spd_learn.modules import GraphBiMap

    X_nodes = make_spd((4, 6), 8, cond=12.0, dtype=torch.float32)
    gbimap = GraphBiMap(in_features=8, out_features=5, n_nodes=6, parametrized=True)
    gbimap.set_graph(torch.full((6, 6), 1.0 / 6.0))
    out = gbimap(X_nodes)
    min_eig = float(torch.linalg.eigvalsh(out).min().item())

    S_clean = make_spd((1, 4), 4, cond=5.0, dtype=torch.float32)
    noise = 0.5 * make_spd((16, 4), 4, cond=3.0, dtype=torch.float32)
    S_noisy = S_clean + noise
    P_smooth = torch.full((4, 4), 0.25)
    S_agg = torch.einsum("ij,bjkl->bikl", P_smooth, S_noisy)
    var_unmixed = float(S_noisy.var(dim=0).mean().item())
    var_mixed = float(S_agg.var(dim=0).mean().item())

    X_fb_tr, y_tr, X_fb_te, y_te = load_real_bnci2014_001_filterbank(
        subject=3, n_chans=12, decim=3
    )
    model = GraphCSPNet(
        n_chans=12,
        n_outputs=4,
        time_steps=[(0, 125), (125, 250)],
        n_freqs=3,
        bi_out=(12, 8),
        k_neighbors=3,
        p_step=2,
        gamma=0.1,
    )
    model.fit_graph(X_fb_tr)
    res = train_and_eval_bnci_classifier(model, X_fb_tr, y_tr, X_fb_te, y_te, epochs=25, lr=8e-3)

    return {
        "ju2023graphcspnet_c1": {
            "min_eig_output": min_eig,
            "output_shape": list(out.shape),
            "passed": min_eig > 0.0 and list(out.shape) == [4, 6, 5, 5],
            "scope": "full",
        },
        "ju2023graphcspnet_c2": {
            "variance_unmixed": var_unmixed,
            "variance_graph_mixed": var_mixed,
            "passed": var_mixed < var_unmixed,
            "scope": "full",
        },
        "ju2023graphcspnet_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "published_mean_pct": 77.55,
            "published_sd_pct": 10.60,

            "our_9subj_harness_sd_pct": 10.90,
