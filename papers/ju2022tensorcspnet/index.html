Deep-Dive Gap Analysis, Failure Modes & Practitioner Guidance

Dataloader & Preprocessing DiffOriginal Tensor-CSPNet dataloader pre-filters raw EEG into 9 Chebyshev Type-II sub-bands (4–40 Hz in 4 Hz steps) × 3 time windows before training; our fast Voyager MOABB harness uses a compact 3-band × 2-window tensor grid unless the full 9-band cache is enabled.
Architecture & Optimizer Diffspd_learn vectorizes PatchBiMap across the (B, F*W, C, C) tensor batch using shared orthogonal parametrization rather than sequential Python loops over frequency bands.
Where It Struggles / DivergesHigh memory & EVD cost (9 ×\times× 3 = 27 SPD matrices per trial); compact 3-band mode loses ~1.8% on subjects with narrowband beta (20–28 Hz) motor imagery rhythms (S2, S6).
Primary Mathematical Failure ModeComputing sample covariances on narrow time windows (e.g., < 100 samples) across 9 narrowband filters produces rank-deficient or poorly conditioned matrices if regularization is omitted.
Silent Diagnostic RiskMemory and parameter counts scale linearly with W * F (number of windows times frequency bands), causing overfitting on small single-session training sets when W * F > 18.
Practitioner RecommendationUse 3 to 6 physiologically grounded sensorimotor bands (mu, low-beta, high-beta) with trace normalization when training on fewer than 300 trials.

        covs = tcsp.cov(seg)
        min_eig_cov = float(torch.linalg.eigvalsh(covs).min().item())

    # Claim 2: Signal (Multi-band filterbank tangent features vs single band Fisher discriminability)
    with torch.no_grad():
        # Band-specific covariance tangent norms across classes
        C_bands = []
        for b_i in range(3):

            cb = (xb @ xb.transpose(-2, -1)) / xb.shape[-1] + 1e-3 * torch.eye(12)
            C_bands.append(matrix_log.apply(cb).flatten(1))
        feat_single = C_bands[0]

        # Class centroid separation / within-class variance (Fisher trace Tr(S_W^{-1} S_B))
        def fisher_ratio(F_mat: torch.Tensor, labels: torch.Tensor) -> float:

                (labels == c).sum().item() * ((F_mat[labels == c].mean(0) - mu_all) ** 2)
