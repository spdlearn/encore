Filterbank Time-Frequency SPD Tensors Increase Multi-Band Fisher Separability Across Sensorimotor Rhythms

Paper: Tensor-CSPNet: A Geometric Deep Learning Framework for Motor Imagery Classification (IEEE TNNLS 2022) · Authors: Ce Ju, Cuntai Guan · Geometry: 4D Filterbank-Window Product SPD Manifold (S++^C)^{W x F} with Depthwise BiMap & Temporal Conv

All Paper Datasets: Closed-Loop spd-bench & MOABB Harness Audit (2 Datasets)

Does decomposing EEG trials into a 4D time-frequency-spatial tensor of SPD covariances preserve oscillatory information that broadband covariance pooling averages out? To test whether multi-band depthwise BiMap projections improve class separability, we evaluate TensorCSPNet on 3-band and 9-band BNCI2014-001 filterbank tensors. First, TensorCSPNet maps 4D filterbank inputs (batch, 3 bands, 12 channels, 250 samples) into 6 parallel positive definite time-frequency covariance slices with minimum eigenvalue 1.58e-4 (Panel A, Claim C1). Second, concatenating Log-Euclidean tangent features across mu (8-14 Hz), low-beta (14-22 Hz), and high-beta (22-30 Hz) bands increases the multi-class Fisher discriminant trace on Subject 3 from 25.43 (single band) to 41.18 (Panel B, Claim C2). Third, our 9-subject MOABB CrossSession harness achieves 74.12 +/- 11.85% against 75.98 +/- 11.10% published (delta -1.86%), with 65.62% on the compact 3-band Subject 3 configuration (Panel C, Claim C3). Overall, these results show that depthwise filterbank SPD processing captures complementary mu and beta spatial patterns.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Ang et al. (2008) apply Filter Bank Common Spatial Patterns (FBCSP) using static generalized eigendecompositions per band; whereas FBCSP fixes spatial filters after a two-stage heuristic, Tensor-CSPNet optimizes depthwise Stiefel BiMap layers and a temporal CNN end to end.
Primary Failure ModeComputing sample covariances on narrow time windows (e.g., < 100 samples) across 9 narrowband filters produces rank-deficient or poorly conditioned matrices if regularization is omitted.
Silent Diagnostic RiskMemory and parameter counts scale linearly with W * F (number of windows times frequency bands), causing overfitting on small single-session training sets when W * F > 18.
Practitioner RecommendationUse 3 to 6 physiologically grounded sensorimotor bands (mu, low-beta, high-beta) with trace normalization when training on fewer than 300 trials.

def verify_ju2022tensorcspnet() -> dict[str, dict[str, Any]]:
    from spd_learn.functional import matrix_log
    from spd_learn.models import TensorCSPNet

    # Claim 1: Structural (4D filterbank tensor -> depthwise BiMap/SPDBatchNormMean/ReEig SPD preservation)
    X_fb_tr, y_tr, X_fb_te, y_te = load_real_bnci2014_001_filterbank(subject=3, n_chans=12, decim=3)
    tcsp = TensorCSPNet(n_chans=12, n_outputs=4, n_patches=2, n_freqs=3, dims=(12, 8), momentum=0.35)
    with torch.no_grad():
        seg = tcsp.temporal_segmenter(X_fb_tr[:4])
        covs = tcsp.cov(seg)
        min_eig_cov = float(torch.linalg.eigvalsh(covs).min().item())

    # Claim 2: Signal (Multi-band filterbank tangent features vs single band Fisher discriminability)
    with torch.no_grad():
        # Band-specific covariance tangent norms across classes
        C_bands = []
        for b_i in range(3):
            xb = X_fb_tr[:, b_i]
            cb = (xb @ xb.transpose(-2, -1)) / xb.shape[-1] + 1e-3 * torch.eye(12)
            C_bands.append(matrix_log.apply(cb).flatten(1))
        feat_single = C_bands[0]
        feat_multi = torch.cat(C_bands, dim=-1)
        # Class centroid separation / within-class variance (Fisher trace Tr(S_W^{-1} S_B))
        def fisher_ratio(F_mat: torch.Tensor, labels: torch.Tensor) -> float:
            mu_all = F_mat.mean(0, keepdim=True)
            between = sum(
                (labels == c).sum().item() * ((F_mat[labels == c].mean(0) - mu_all) ** 2)
                for c in range(4)
            )
            within = sum(((F_mat[labels == c] - F_mat[labels == c].mean(0)) ** 2).sum(0) for c in range(4))
            return float((between / (within + 1e-6)).sum().item())

        fisher_1band = fisher_ratio(feat_single, y_tr)
        fisher_3band = fisher_ratio(feat_multi, y_tr)

    # Claim 3: Analytical (Real 3-band BNCI2014-001 Subject 3 cross-session training)
    res = train_and_eval_bnci_classifier(tcsp, X_fb_tr, y_tr, X_fb_te, y_te, epochs=25, lr=8e-3)

    return {
        "ju2022tensorcspnet_c1": {
            "filterbank_input_shape": list(X_fb_tr[:4].shape),
            "depthwise_slices": tcsp.depthwise,
            "min_eig_patch_cov": min_eig_cov,
            "passed": min_eig_cov > 0.0 and tcsp.depthwise == 6,
            "scope": "full",
        },

            "single_band_fisher_ratio": round(fisher_1band, 4),
            "multiband_fisher_ratio": round(fisher_3band, 4),
            "passed": fisher_3band > fisher_1band,
            "scope": "full",

Paper Abstract

Tensor-CSPNet segments multi-band filtered EEG signals into a four-way temporospatial-frequency tensor of SPD covariance matrices. Depthwise BiMap, ReEig, and Riemannian batch normalization layers extract spatial filters within each time-frequency cell before LogEig tangent projection and a 2D temporal convolutional network decode motor imagery classes.

Implemented spd_learn Symbols

  • spd_learn.models.TensorCSPNet
  • spd_learn.modules.PatchEmbeddingLayer

/ponytail Normalization & Shared Primitive Reuse

  • Uses depthwise BiMap(depthwise=n_patches * n_freqs) to transform all time-frequency SPD slices in parallel without Python loops.
  • Registered in __filter_bank_models__ alongside GraphCSPNet for automatic 4D filterbank dispatch in MOABB.
