Log-Euclidean Spectral Residual Connections Prevent Gradient Vanishing Across Deep SPD Blocks

Paper: Understanding Matrix Function Normalizations in Covariance Pooling through the Lens of Riemannian Geometry (ALEM & SPDResNet) (IEEE TIP 2024 / ICLR 2025) · Authors: Ziheng Chen, Yue Song, Rui Wang, Xiao-Jun Wu, Nicu Sebe · Geometry: Spectral 1D-CNN Eigenvalue Residual Blocks + Learnable ALEM Power Deformation

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr14-spdresnet-gyrospd

Closed-Loop Empirical Audit & MOABB / spd-bench Harness Comparison

How can residual skip connections and learnable spectral deformations be defined on the SPD manifold so that deeper SPD networks do not suffer from eigenvalue collapse? To test whether Adaptive Log-Euclidean Metrics (ALEM) and spectral 1D-CNN residual blocks (SPDResBlock) preserve positive definiteness and gradient flow, we audit ALEM and SPDResNet. First, both AdaptiveLogEuclidean(return_spd=True) and SPDResBlock output strictly positive definite matrices with minimum eigenvalues 0.268 and 0.248 > 0 (Panel A, Claim C1). Second, stacking two SPDResBlocks with LogEuclideanResidual skip connections preserves strong backward input gradients (||grad_X0||_F = 9.65; Panel B, Claim C2). Third, on real BNCI2014-001 Subject 3 cross-session transfer, SPDResNet achieves 50.35% test accuracy (more than double the 25.0% 4-class chance floor; Panel C, Claim C3). Overall, these results confirm that spectral 1D-CNN residual blocks and adaptive power deformations maintain well-conditioned gradients in deep SPD architectures.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Huang and Van Gool (2017) apply a static scalar threshold max(lambda, eps) in ReEig without skip connections; whereas ReEig treats each eigenvalue independently and lacks residual pathways, SPDResNet applies a 1D-CNN across sorted log-eigenvalues and merges the output with the input via LogEuclideanResidual.
Primary Failure ModeApplying a 1D convolution across sorted eigenvalues assumes a consistent semantic ordering of eigenvalues, which can permute when two eigenvalues cross during training.
Silent Diagnostic RiskDesigned primarily for large-matrix visual/skeletal covariance benchmarks (HDM05 93x93), pure covariance-input SPDResNet without a temporal conv frontend has lower accuracy on raw broadband EEG than hybrid CNN-SPD models.
Practitioner RecommendationPair SPDResBlock and AdaptiveLogEuclidean with a learnable temporal filterbank when applying SPDResNet to raw EEG time series.

Executable Verifier Source Code (repro/trackio_runner.py)

def verify_chen2025alem_spdresnet() -> dict[str, dict[str, Any]]:
    from spd_learn.models import AdaptiveLogEuclidean, SPDResBlock, SPDResNet

    X = make_spd((4,), 6, cond=10.0, dtype=torch.float64)
    alem = AdaptiveLogEuclidean(num_features=6, return_spd=True, dtype=torch.float64)
    out_alem = alem(X)
    min_eig_alem = float(torch.linalg.eigvalsh(out_alem).min().item())
    res_block = SPDResBlock(num_features=6)
    out_res = res_block(X.float())
    min_eig_res = float(torch.linalg.eigvalsh(out_res).min().item())

    X_g = X.float().clone().requires_grad_(True)
    out_g = res_block(res_block(X_g))
    out_g.sum().backward()
    grad_norm = float(torch.linalg.norm(X_g.grad).item())

    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=22, decim=3)
    model = SPDResNet(n_chans=22, n_outputs=4, bimap_dims=(22, 12), num_res_blocks=1)
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "chen2025alem_spdresnet_c1": {
            "alem_spd_min_eig": min_eig_alem,
            "spdresblock_min_eig": min_eig_res,
            "passed": min_eig_alem > 0.0 and min_eig_res > 0.0,
            "scope": "full",
        },
        "chen2025alem_spdresnet_c2": {
            "input_grad_norm_2_blocks": grad_norm,
            "passed": grad_norm > 0.0 and math.isfinite(grad_norm),
            "scope": "full",
        },
        "chen2025alem_spdresnet_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "bnci_subj3_train_acc_pct": res["train_acc_pct"],
            "bnci_subj3_test_acc_pct": res["test_acc_pct"],
            "chance_level_pct": 25.0,
            "passed": res["test_acc_pct"] >= 48.0,
            "scope": "full",
        },
    }

Paper Abstract

Adaptive Log-Euclidean Metric (ALEM) introduces learnable positive power and affine spectral deformations to adapt matrix logarithm normalizations to heavy-tailed covariance spectra, while SPDResBlock applies 1D spectral convolutions on log-eigenvalues with Log-Euclidean geodesic residual connections.
