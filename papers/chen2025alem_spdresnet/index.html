Paper Abstract & Core Formulation

Adaptive Log-Euclidean Metric (ALEM) introduces learnable positive power and affine spectral deformations to adapt matrix logarithm normalizations to heavy-tailed covariance spectra, while SPDResBlock applies 1D spectral convolutions on log-eigenvalues with Log-Euclidean geodesic residual connections.

Deep-Dive Gap Analysis, Failure Modes & Practitioner Guidance

Dataloader & Preprocessing DiffPaper evaluates skeletal action (HDM05, FPHA) and EEG cov matrices; spd-bench matches the official splits with trace-scaled shrinkage on FPHA.
Architecture & Optimizer Diffspd_learn implements AdaptiveLogEuclidean (ALEM with per-eigenvalue power α_i > 0) and SPDResBlock (1D-CNN residual blocks directly on sorted log-eigenvalue spectra).
Where It Struggles / DivergesApplying 1D convolutions across sorted eigenvalues assumes adjacent eigenvalue indices remain aligned across trials, which can swap when two eigenvalues cross (coalescence).
Primary Mathematical Failure ModeApplying a 1D convolution across sorted eigenvalues assumes a consistent semantic ordering of eigenvalues, which can permute when two eigenvalues cross during training.
Silent Diagnostic RiskDesigned primarily for large-matrix visual/skeletal covariance benchmarks (HDM05 93×9393 \times 9393×93), pure covariance-input SPDResNet without a temporal conv frontend has lower accuracy on raw broadband EEG than hybrid CNN-SPD models.
Practitioner RecommendationPair SPDResBlock and AdaptiveLogEuclidean with a learnable temporal filterbank when applying SPDResNet to raw EEG time series.

def verify_chen2025alem_spdresnet() -> dict[str, dict[str, Any]]:
    from spd_learn.models import SPDResNet
    from spd_learn.models.spdresnet import AdaptiveLogEuclidean, SPDResBlock

    X = make_spd((4,), 6, cond=10.0, dtype=torch.float64)
    alem = AdaptiveLogEuclidean(num_features=6, return_spd=True, dtype=torch.float64)
    out_alem = alem(X)
    min_eig_alem = float(torch.linalg.eigvalsh(out_alem).min().item())
    res_block = SPDResBlock(num_features=6)
    out_res = res_block(X.float())
    min_eig_res = float(torch.linalg.eigvalsh(out_res).min().item())

    X_g = X.float().clone().requires_grad_(True)
    out_g = res_block(res_block(X_g))
    out_g.sum().backward()
    grad_norm = float(torch.linalg.norm(X_g.grad).item())

    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=22, decim=3)
    model = SPDResNet(n_chans=22, n_outputs=4, bimap_dims=(22, 12), num_res_blocks=1)
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "chen2025alem_spdresnet_c1": {
            "alem_spd_min_eig": min_eig_alem,
            "spdresblock_min_eig": min_eig_res,
            "passed": min_eig_alem > 0.0 and min_eig_res > 0.0,
            "scope": "full",
        },
        "chen2025alem_spdresnet_c2": {
            "input_grad_norm_2_blocks": grad_norm,
            "passed": grad_norm > 0.0 and math.isfinite(grad_norm),
            "scope": "full",
        },
        "chen2025alem_spdresnet_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "bnci_subj3_train_acc_pct": res["train_acc_pct"],
            "bnci_subj3_test_acc_pct": res["test_acc_pct"],
            "chance_level_pct": 25.0,
            "passed": res["test_acc_pct"] >= 48.0,
            "scope": "full",
        },
    }
