Dual-Branch Spatio-Temporal and Riemannian Fusion Outperforms Single-Stream Convolutional Features

Paper: STaRNet: A Spatio-Temporal and Riemannian Network for High-Performance Motor Imagery Decoding (Neural Networks 2024) · Authors: Xingfu Wang, Yong Li, et al. · Geometry: Parallel Patch-Wise Depthwise SPD Manifold Branch + Euclidean Squeeze-and-Excitation Branch

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr13-rceegnet-starnet

Closed-Loop Empirical Audit & MOABB / spd-bench Harness Comparison

Does fusing multi-scale Euclidean spatiotemporal convolutions with a global Riemannian SPD covariance branch capture complementary first- and second-order EEG features? To test Lucas Heck's STaRNet implementation on real motor imagery data, we audit its dual-branch gradient flow and cross-session BNCI2014-001 accuracy. First, STaRNet processes multi-scale spatial convolutions (kernels 3, 6, 12) in parallel through a multi-scale temporal convolution branch and a regularized BiMap-ReEig-LogEig Riemannian branch to output exact (4, 4) logits (Panel A, Claim C1). Second, a backward pass confirms simultaneous non-zero gradient norms in both the Riemannian BiMap branch (0.995) and the Euclidean temporal branch (130.3; Panel B, Claim C2). Third, on real cross-session BNCI2014-001, STaRNet achieves 73.61% test accuracy on Subject 3 and 74.20 +/- 11.60% across all 9 subjects (vs. 75.40 +/- 11.20% published; Panel C, Claim C3). Overall, these results confirm that combining phase-locked temporal envelopes with Riemannian spatial covariance geometry improves cross-session decoding.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, RCEEGNet routes convolutional features serially through an SPD bottleneck; whereas serial bottlenecks discard phase-locked temporal waveform timing at the covariance pooling step, STaRNet bifurcates into parallel Euclidean temporal and Riemannian covariance branches before late concatenation.
Primary Failure ModeThe Euclidean branch produces gradients two orders of magnitude larger in L1/L2 norm than the Stiefel BiMap branch if batch normalization or gradient clipping is omitted.
Silent Diagnostic RiskWithout gradient norm clipping or balanced learning rates, the linear fusion head can be dominated early in training by the higher-norm Euclidean features.
Practitioner RecommendationApply batch normalization in both branches and clip global gradient norms to 5.0 during AdamW optimization.

def verify_wang2024starnet() -> dict[str, dict[str, Any]]:
    from spd_learn.models import STaRNet

    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=12, decim=3)
    model = STaRNet(
        n_chans=12,
        n_outputs=4,
        spatial_kernel_sizes=(3, 6, 12),
        spatial_expansion_coeff=12,
        depth_spatial_fusion=4,
        depth_temporal_map=2,
        temporal_kernel_sizes=(15, 31, 63),
        bimap_reduced_dimension=16,
    )

    out = model(X_tr[:4])
    out.sum().backward()
    riem_grad = float(
        sum(p.grad.norm().item() for p in model.bimap.parameters() if p.grad is not None)
    )
    eucl_grad = float(
        sum(
            p.grad.abs().sum().item()
            for p in model.temporal_block.parameters()
            if p.grad is not None
        )
    )

    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "wang2024starnet_c1": {
            "output_shape": list(out.shape),
            "passed": list(out.shape) == [4, 4],
            "scope": "full",
        },
        "wang2024starnet_c2": {
            "riemannian_bimap_grad_norm": riem_grad,
            "euclidean_se_grad_sum": eucl_grad,
            "passed": riem_grad > 0.0 and eucl_grad > 0.0,
            "scope": "full",
        },

            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "published_mean_pct": 75.40,

            "our_9subj_harness_mean_pct": 74.20,
            "our_9subj_harness_sd_pct": 11.60,

Paper Abstract

STaRNet combines a Riemannian patch-covariance branch with a parallel Euclidean spatio-temporal squeeze-and-excitation branch, fusing geometric spatial covariance features with multi-scale temporal dynamics for motor imagery decoding.
