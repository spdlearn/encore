Paper Abstract & Core Formulation

SPDNet introduces a deep neural network architecture operating directly on Symmetric Positive Definite (SPD) covariance matrices. It defines three core layers: Bilinear Mapping (BiMap) via semi-orthogonal Stiefel weights for dimensionality reduction, Eigenvalue Rectification (ReEig) to clamp small eigenvalues above a positive threshold epsilon, and Eigenvalue Logarithm (LogEig) to project the final SPD representation onto the flat symmetric tangent space at the identity before linear classification.

Deep-Dive Root-Cause Attribution (Original Authors' Code vs. Our Code), Failure Modes & Practitioner Guidance

Original Authors' Code / Protocol Root CauseOriginal MATLAB repo (zzhiwu/SPDNet) loads pre-computed .mat covariance descriptors on a single fixed random split without temporal filtering or BatchNorm, and reports peak test-set accuracy over epochs.
Our spd_learn Code / Harness Fix AppliedNormalized SPDNet in spd_learn with orthogonal trivialization (BiMap), ReEig(1e-4), and trace-scaled shrinkage. On Voyager HDM05 (3 seeds, 60 ep), SPDNet reaches 58.04±0.6358.04 \pm 0.6358.04±0.63% (final 57.69%), and on BNCI2014-001 reaches 62.81±16.5062.81 \pm 16.5062.81±16.50% (final 61.81%).
Dataloader & Preprocessing DiffPaper loads pre-computed MATLAB .mat descriptors on a single fixed split; Voyager recomputes sample covariances across 3 random holdout_split(0.5) seeds on HDM05 and 9 BNCI2014-001 CrossSession subjects.
Architecture & Optimizer DiffPaper uses custom MATLAB QR-retraction SGD; spd_learn uses PyTorch orthogonal trivialization (Cayley/Householder) + AdamW.
Where It Struggles / DivergesWithout temporal convolutions or Riemannian BatchNorm, SPDNet suffers severe cross-session drift on low-SNR EEG subjects (BNCI2014-001 S2: 47.57%, S6: 41.67%).
Primary Mathematical Failure ModeLoewner matrix entries 1 / (lambda_i - lambda_j) during eigendecomposition backward passes blow up when adjacent eigenvalues coalesce or fall below float32 precision.
Silent Diagnostic RiskSilent NaN gradients in deep BiMap stacks when input sample covariances are rank-deficient (T < C) and no Shrinkage or TraceNorm precedes the first BiMap layer.
Practitioner RecommendationPrecede SPDNet with trace normalization and shrinkage regularization on short-window EEG trials, and use float64 eigendecompositions when condition numbers exceed 10510^{5}105.
