Original Protocol / Code Issue

Original MATLAB repo (zzhiwu/SPDNet) loads pre-computed .mat covariance descriptors on a single fixed random split without temporal filtering or BatchNorm.

Our spd_learn Fix

Normalized SPDNet in spd_learn with orthogonal trivialization (BiMap), ReEig(1e-4), and trace-scaled shrinkage.

Where It Struggles

Without temporal convolutions or Riemannian BatchNorm, SPDNet suffers severe cross-session drift on low-SNR EEG subjects (BNCI2014-001 S2: 47.57%, S6: 41.67%) and 400×400400 \times 400400×400 AFEW (28.36%).

Original Protocol / Code IssueOriginal MATLAB repo (zzhiwu/SPDNet) loads pre-computed .mat covariance descriptors on a single fixed random split without temporal filtering or BatchNorm.
Our spd_learn Fix AppliedNormalized SPDNet in spd_learn with orthogonal trivialization (BiMap), ReEig(1e-4), and trace-scaled shrinkage.
Dataloader & Preprocessing DiffPaper loads pre-computed MATLAB .mat descriptors on a single fixed split.
Architecture & Optimizer DiffPaper uses custom MATLAB QR-retraction SGD; spd_learn uses PyTorch orthogonal trivialization (Cayley/Householder) + AdamW.
Where It Struggles / DivergesWithout temporal convolutions or Riemannian BatchNorm, SPDNet suffers severe cross-session drift on low-SNR EEG subjects (BNCI2014-001 S2: 47.57%, S6: 41.67%) and 400×400400 \times 400400×400 AFEW (28.36%).
Practitioner RecommendationPrecede SPDNet with trace normalization and shrinkage regularization on short-window EEG trials.

Paper Abstract

SPDNet introduces a deep neural network architecture operating directly on Symmetric Positive Definite (SPD) covariance matrices. It defines three core layers: Bilinear Mapping (BiMap) via semi-orthogonal Stiefel weights for dimensionality reduction, Eigenvalue Rectification (ReEig) to clamp small eigenvalues above a positive threshold epsilon, and Eigenvalue Logarithm (LogEig) to project the final SPD representation onto the flat symmetric tangent space at the identity before linear classification.
