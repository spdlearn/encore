Paper Overview & Mathematical Spec A Riemannian Network for SPD Matrix Learning (SPDNet) (AAAI 2017) 3 Figures · 3 Paper Tables · 5 Voyager Benchmarks
Paper Abstract & Core Formulation

SPDNet introduces a deep neural network architecture operating directly on Symmetric Positive Definite (SPD) covariance matrices. It defines three core layers: Bilinear Mapping (BiMap) via semi-orthogonal Stiefel weights for dimensionality reduction, Eigenvalue Rectification (ReEig) to clamp small eigenvalues above a positive threshold epsilon, and Eigenvalue Logarithm (LogEig) to project the final SPD representation onto the flat symmetric tangent space at the identity before linear classification.

/ponytail Primitive Reuse & Engineering Notes
  • Serves as the canonical 3-layer Riemannian backbone (BiMap →\to→ ReEig →\to→ LogEig) reused across 19 of the 26 models in spd_learn.
  • Uses torch.nn.utils.parametrize with orthogonal Stiefel projection on BiMap weights and analytical Loewner matrix gradients in ReEig and LogEig.

Deep-Dive Gap Analysis, Failure Modes & Practitioner Guidance

Dataloader & Preprocessing DiffPaper loads pre-computed MATLAB .mat covariance descriptors on fixed random splits; spd-bench recomputes sample covariances from raw skeletal/radar/EEG windows with trace-scaled shrinkage (ϵ=10−4\epsilon = 10^{-4}ϵ=10−4) for rank-deficient FPHA trials (T < 63).
Architecture & Optimizer DiffPaper uses custom MATLAB Riemannian SGD with manual QR Stiefel retraction; spd_learn uses PyTorch orthogonal trivialization (Cayley/Householder) + AdamW/AMSGrad.
Where It Struggles / DivergesStruggles on raw multi-channel EEG (BNCI2014-001 S2: 37.5%, S6: 43.1%) because SPDNet lacks temporal band-pass convolutions and Riemannian batch normalization.
Primary Mathematical Failure ModeLoewner matrix entries 1 / (lambda_i - lambda_j) during eigendecomposition backward passes blow up when adjacent eigenvalues coalesce or fall below float32 precision.
Silent Diagnostic RiskSilent NaN gradients in deep BiMap stacks when input sample covariances are rank-deficient (T < C) and no Shrinkage or TraceNorm precedes the first BiMap layer.
Practitioner RecommendationPrecede SPDNet with trace normalization and shrinkage regularization on short-window EEG trials, and use float64 eigendecompositions when condition numbers exceed 10510^{5}105.

def verify_huang2017spdnet() -> dict[str, dict[str, Any]]:
    from spd_learn.models import SPDNet
    from spd_learn.modules import BiMap, LogEig, ReEig

    # Claim 1: Structural (BiMap Stiefel orthogonality + ReEig threshold + LogEig dim)
    torch.manual_seed(42)
    bimap = BiMap(in_features=12, out_features=8, parametrized=True)
    reeig = ReEig(threshold=1e-4)
    logeig = LogEig(upper=True, flatten=True)
    W = bimap.weight[0]
    orth_err = float(torch.linalg.norm(W.T @ W - torch.eye(8)).item())
    X_in = make_spd((6,), 12, cond=1e5, dtype=torch.float32)
    X_sub = reeig(bimap(X_in))
    min_eig = float(torch.linalg.eigvalsh(X_sub).min().item())
    vec_out = logeig(X_sub)

    # Claim 2: Signal (Real HDM05 93x93 covariances: condition number compression & finite grad)
    X_hdm = load_real_hdm05_batch(16).requires_grad_(True)
    eigs_raw = torch.linalg.eigvalsh(X_hdm.detach())
    kappa_raw = float((eigs_raw[:, -1] / eigs_raw[:, 0].clamp_min(1e-12)).median().item())
    bimap_hdm = BiMap(in_features=93, out_features=30)
    reeig_hdm = ReEig(threshold=1e-4)
    Y_hdm = reeig_hdm(bimap_hdm(X_hdm))
    Y_hdm.sum().backward()
    eigs_post = torch.linalg.eigvalsh(Y_hdm.detach())
    kappa_post = float((eigs_post[:, -1] / eigs_post[:, 0]).median().item())
    grad_finite = bool(torch.isfinite(X_hdm.grad).all().item())

    model = SPDNet(n_chans=22, n_outputs=4, subspacedim=22)
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)
