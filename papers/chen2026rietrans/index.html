Inter-Layer Log/Exp Cancellation Eliminates Intermediate Eigendecompositions in Pullback SPD Perceptrons

Paper: Riemannian Transformations for SPD Neural Networks (RieTrans & RMLR) (NeurIPS 2024 / NeurIPS 2026) · Authors: Ziheng Chen, Yue Song, Rui Wang, Xiao-Jun Wu, Nicu Sebe · Geometry: Pullback Tangent Linear & Multinomial Logistic Regression (LEM, LCM, AIM, PEM)

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr3-rietrans-gyroatt

Closed-Loop Empirical Audit & MOABB / spd-bench Harness Comparison

Why do multi-layer pullback SPD perceptrons perform two O(d^3) eigendecompositions at every hidden layer when consecutive exponential and logarithmic maps cancel analytically? To test whether tangent-space chaining (return_tangent=True, input_tangent=True) matches manifold-to-manifold SPDLinear stacks while supporting unified Riemannian Multinomial Logistic Regression (SPDRMLR), we evaluate RieTrans and SPNN. First, a two-layer tangent-chained SPDLinear stack matches the full Exp/Log manifold stack to relative error 4.21e-7 while eliminating all intermediate eigendecompositions (Panel A, Claim C1). Second, SPDRMLR produces finite, well-scaled backward gradients across all four Riemannian metrics (LEM, LCM, AIM, and PEM; Panel B, Claim C2). Third, on real BNCI2014-001 Subject 3 cross-session transfer, SPNN achieves 65.28% test accuracy (vs. 25.0% chance; Panel C, Claim C3). Overall, these results show that pullback tangent algebra unifies multi-layer SPD perceptrons and multinomial logistic regression without redundant spectral factorizations.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Nguyen et al. (2024) define gyrovector linear layers on S++^d via Log/Exp maps at every layer; whereas naive pullback layers re-exponentiate and re-logarithmize between affine transformations, RieTrans cancels adjacent Exp_I and Log_I maps.
Primary Failure ModeFull dense tangent-space weight matrices W in R^{m_out x m_in} have O(d^4) parameters (since m = d(d+1)/2), which overfits rapidly when d > 16 on small EEG datasets.
Silent Diagnostic RiskWhen non-identity reference matrices P != I are learned under AIM without tangent parallel transport, Log_P(Exp_Q(V)) no longer cancels to the identity map.
Practitioner RecommendationKeep hidden SPD dimensions compact (d <= 12) or combine BiMap spatial reduction with SPDRMLR classification heads.

def verify_chen2026rietrans() -> dict[str, dict[str, Any]]:
    from spd_learn.models import SPNN
    from spd_learn.modules import SPDLinear, SPDRMLR

    torch.manual_seed(42)
    X = make_spd((8,), 6, cond=10.0, dtype=torch.float32)
    l1_full = SPDLinear(6, 5, metric="LEM", return_tangent=False)
    l2_full = SPDLinear(5, 4, metric="LEM", input_tangent=False, return_tangent=False)

    l1_fast = SPDLinear(6, 5, metric="LEM", return_tangent=True)
    l2_fast = SPDLinear(5, 4, metric="LEM", input_tangent=True, return_tangent=False)
    l1_fast.load_state_dict(l1_full.state_dict())
    l2_fast.load_state_dict(l2_full.state_dict())
    with torch.no_grad():
        l2_full.rmlr.reference = torch.eye(5)
        l2_fast.rmlr.reference = torch.eye(5)
        out_full = l2_full(l1_full(X))
        out_fast = l2_fast(l1_fast(X))
        chain_err = float(
            (torch.linalg.norm(out_full - out_fast) / torch.linalg.norm(out_full)).item()
        )

    metrics_ok = {}
    for m in ("LEM", "LCM", "AIM", "PEM"):
        rmlr = SPDRMLR(n_features=5, n_outputs=3, metric=m, theta=0.5)
        X_m = make_spd((4,), 5, cond=8.0, dtype=torch.float32).requires_grad_(True)
        loss = rmlr(X_m).sum()
        loss.backward()
        metrics_ok[m] = bool(torch.isfinite(X_m.grad).all().item())

    # Claim 3: Analytical on real BNCI2014-001 Subject 3 cross-session
    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=12, decim=3)
    model = SPNN(n_chans=12, n_outputs=4, hidden_dims=(10, 8), metric="LEM")
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "chen2026rietrans_c1": {
            "tangent_chaining_rel_error": chain_err,
            "passed": chain_err < 1e-4,
            "scope": "full",
        },
        "chen2026rietrans_c2": {
            "metrics_grad_finite": metrics_ok,
            "passed": all(metrics_ok.values()),
            "scope": "full",
        },
        "chen2026rietrans_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "bnci_subj3_train_acc_pct": res["train_acc_pct"],
            "bnci_subj3_test_acc_pct": res["test_acc_pct"],
            "chance_level_pct": 25.0,
            "passed": res["test_acc_pct"] >= 58.0,
            "scope": "full",
        },
    }

Paper Abstract

We formulate a general framework for Riemannian Multinomial Logistic Regression (SPDRMLR) and intrinsic SPD Fully-Connected Transformation layers (SPDLinear) across deformed SPD geometries (LEM, LCM, AIM, PEM). By mapping multi-channel SPD inputs through unidirectional Riemannian hyperplanes into symmetric tangent coordinates and exponentiating only when manifold outputs are required, chained SPDLinear layers eliminate redundant intermediate eigendecompositions.
