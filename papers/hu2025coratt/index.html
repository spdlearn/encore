Correlation Manifold Self-Attention Achieves Exact Invariance to Per-Electrode Amplitude Scaling

Paper: A Correlation Manifold Self-Attention Network for EEG Decoding (IJCAI 2025) · Authors: Chen Hu, Rui Wang, Ziheng Chen, Xiao-Jun Wu, Xiaoning Song · Geometry: Full-Rank Correlation Manifold $\mathcal{C}_{++}^{d}$ (LSM & OLM)

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr2-coratt-cornet

All Paper Datasets: Closed-Loop spd-bench & MOABB Harness Audit (3 Datasets)

Do per-channel amplitude fluctuations and electrode impedance drifts corrupt covariance-based manifold self-attention? To test whether projecting patch covariances onto the full-rank correlation manifold $\mathcal{C}_{++}^{d}$ eliminates scale sensitivity, we compare CorAtt against covariance-based MAtt under random channel gain perturbations and on real BNCI2014-001 recordings. First, Off-Log (OLM) and Log-Scaled (LSM) maps on $\mathcal{C}_{++}^{d}$ produce hollow symmetric tangent matrices (diagonal error 0.0) and unit-diagonal correlation matrices on exponential roundtrip (error 3.29e-7; Panel A, Claim C1). Second, under random per-channel gain perturbations $D S D$ with dynamic range 25x, CorrAttention output drift remains at the float32 floor (3.63e-7), whereas covariance-based AttentionManifold drifts by 10.43x (Panel B, Claim C2). Third, on real cross-session BNCI2014-001, CorAtt reaches 75.35% on Subject 3 and $74.65 \pm 11.10$% across 9 subjects, matching the published $75.81 \pm 10.90$% score (Panel C, Claim C3). Overall, these results show that quotienting out diagonal variance before self-attention prevents high-amplitude channel artifacts from dominating attention weights.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Pan et al. (2022) apply Log-Euclidean self-attention to trace-normalized covariance patches; whereas TraceNorm only normalizes the global sum of variances across channels, CorAtt normalizes each channel variance individually via D^{-1/2} S D^{-1/2} onto $\mathcal{C}_{++}^{d}$.
Primary Failure ModeThe fixed-point diagonal scaling iteration inside corr_olm_exp and corr_lsm_log adds per-patch overhead if run for many iterations on large correlation matrices.
Silent Diagnostic RiskDiscarding diagonal channel variances removes task information whenever band-power amplitude itself (rather than inter-channel phase locking) is the primary discriminative feature.
Practitioner RecommendationUse CorAtt with metric='mix' (combining LSM, OLM, and ECM) when cross-session impedance shifts are severe, and limit OLM/LSM fixed-point solvers to 6 iterations.

def verify_hu2025coratt() -> dict[str, dict[str, Any]]:
    from spd_learn.functional import (
        corr_lsm_exp,
        corr_lsm_log,
        corr_olm_exp,
        corr_olm_log,
        cov_to_corr,
    )
    from spd_learn.models import AttentionManifold, CorAtt, CorrAttention

    S = make_spd((4,), 6, cond=15.0, dtype=torch.float32)
    C = cov_to_corr(S)
    olm_tan = corr_olm_log(C)
    lsm_tan = corr_lsm_log(C)
    C_olm_rec = corr_olm_exp(olm_tan)
    C_lsm_rec = corr_lsm_exp(lsm_tan)
    hollow_err = float(
        max(
            torch.diagonal(olm_tan, dim1=-2, dim2=-1).abs().max().item(),
            torch.diagonal(lsm_tan, dim1=-2, dim2=-1).abs().max().item(),
        )
    )
    unit_diag_err = float(
        max(
            (torch.diagonal(C_olm_rec, dim1=-2, dim2=-1) - 1.0).abs().max().item(),
            (torch.diagonal(C_lsm_rec, dim1=-2, dim2=-1) - 1.0).abs().max().item(),
        )
    )
    olm_roundtrip_err = float(torch.linalg.norm(C - C_olm_rec).item() / torch.linalg.norm(C).item())

    torch.manual_seed(7)
    S_patch = make_spd((2, 4), 6, cond=10.0, dtype=torch.float32)
    gains = torch.empty(2, 1, 6).uniform_(0.2, 5.0)
    S_scaled = gains.unsqueeze(-1) * S_patch * gains.unsqueeze(-2)
    corr_att = CorrAttention(dim=6, metric="mix").eval()
    cov_att = AttentionManifold(in_features=6, out_features=6).eval()
    with torch.no_grad():
        out_corr_1 = corr_att(cov_to_corr(S_patch))
        out_corr_2 = corr_att(cov_to_corr(S_scaled))
        corr_drift = float(
            (torch.linalg.norm(out_corr_1 - out_corr_2) / torch.linalg.norm(out_corr_1)).item()
        )
        out_cov_1 = cov_att(S_patch)
        out_cov_2 = cov_att(S_scaled)
        cov_drift = float(
            (torch.linalg.norm(out_cov_1 - out_cov_2) / torch.linalg.norm(out_cov_1)).item()
        )

Paper Abstract

Correlation matrices live on the quotient/submanifold of full-rank SPD matrices with unit diagonal. Existing SPD attention mechanisms distort unit-diagonal invariance when applied to correlation connectivity. We propose CorAtt, a Riemannian self-attention network over the full-rank correlation manifold using Off-Log Metric (OLM) and Log-Scaled Metric (LSM) diffeomorphisms to hollow symmetric tangent spaces, enabling geometry-preserving Q/K/V transformations and correlation barycenter aggregation for EEG decoding.
