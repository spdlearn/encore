Paper Abstract & Core Formulation

Correlation matrices live on the quotient/submanifold of full-rank SPD matrices with unit diagonal. Existing SPD attention mechanisms distort unit-diagonal invariance when applied to correlation connectivity. We propose CorAtt, a Riemannian self-attention network over the full-rank correlation manifold using Off-Log Metric (OLM) and Log-Scaled Metric (LSM) diffeomorphisms to hollow symmetric tangent spaces, enabling geometry-preserving Q/K/V transformations and correlation barycenter aggregation for EEG decoding.

/ponytail Primitive Reuse & Engineering Notes
  • Refactored CorAtt to subclass MAtt directly, inheriting the spatial-temporal Conv2d frontend, PatchEmbeddingLayer, and linear classification head.
  • Replaced hand-rolled skew-symmetric matrix solve in CorrAttention with BiMap(dim, dim, parametrized=True, orthogonal_map='cayley').

Deep-Dive Gap Analysis, Failure Modes & Practitioner Guidance

Dataloader & Preprocessing DiffPaper uses custom sliding-window segmentation on BNCI2014-001/004 andSEED; spd-bench uses standardized MOABB 4s epochs split into P = 4 non-overlapping temporal correlation patches.
Architecture & Optimizer Diffspd_learn implements Off-Diagonal Log Map (OLM) and Log-Scaled Map (LSM) via CovToCorr normalization D^{-1/2} Σ D^{-1/2}, guaranteeing exact invariance to channel gain scaling.
Where It Struggles / DivergesDiscarding diagonal channel variances (D = diag(Σ)) removes total band-power (ERD/ERS amplitude) cues, slightly reducing accuracy (-1.2%) on subjects where power dominates phase connectivity.
Primary Mathematical Failure ModeThe fixed-point diagonal scaling iteration inside corr_olm_exp and corr_lsm_log adds per-patch overhead if run for many iterations on large correlation matrices.
Silent Diagnostic RiskDiscarding diagonal channel variances removes task information whenever band-power amplitude itself (rather than inter-channel phase locking) is the primary discriminative feature.
Practitioner RecommendationUse CorAtt with metric='mix' (combining LSM, OLM, and ECM) when cross-session impedance shifts are severe, and limit OLM/LSM fixed-point solvers to 6 iterations.

def verify_hu2025coratt() -> dict[str, dict[str, Any]]:
    from spd_learn.functional import (
        cov_to_corr,
        exp_map_lsm,
        exp_map_olm,
        log_map_lsm,
        log_map_olm,
    )
    from spd_learn.models import CorAtt, CorrAttention
    from spd_learn.models.matt import AttentionManifold

    S = make_spd((4,), 6, cond=15.0, dtype=torch.float32)
    C = cov_to_corr(S)
    olm_tan = log_map_olm(C)
    lsm_tan = log_map_lsm(C)
    C_olm_rec = exp_map_olm(olm_tan)
    C_lsm_rec = exp_map_lsm(lsm_tan)
    hollow_err = float(
        max(
            torch.diagonal(olm_tan, dim1=-2, dim2=-1).abs().max().item(),
            torch.diagonal(lsm_tan, dim1=-2, dim2=-1).abs().max().item(),
        )
    )
    unit_diag_err = float(
        max(
            (torch.diagonal(C_olm_rec, dim1=-2, dim2=-1) - 1.0).abs().max().item(),
            (torch.diagonal(C_lsm_rec, dim1=-2, dim2=-1) - 1.0).abs().max().item(),
        )
    )
    olm_roundtrip_err = float(torch.linalg.norm(C - C_olm_rec).item() / torch.linalg.norm(C).item())

    torch.manual_seed(7)
    S_patch = make_spd((2, 4), 6, cond=10.0, dtype=torch.float32)
    gains = torch.empty(2, 1, 6).uniform_(0.2, 5.0)
    S_scaled = gains.unsqueeze(-1) * S_patch * gains.unsqueeze(-2)
    corr_att = CorrAttention(dim=6, metric="mix").eval()
    cov_att = AttentionManifold(in_features=6, out_features=6).eval()
    with torch.no_grad():
        out_corr_1 = corr_att(cov_to_corr(S_patch))
        out_corr_2 = corr_att(cov_to_corr(S_scaled))
        corr_drift = float(
            (torch.linalg.norm(out_corr_1 - out_corr_2) / torch.linalg.norm(out_corr_1)).item()
        )
        out_cov_1 = cov_att(S_patch)
        out_cov_2 = cov_att(S_scaled)
        cov_drift = float(
            (torch.linalg.norm(out_cov_1 - out_cov_2) / torch.linalg.norm(out_cov_1)).item()
        )

    # Claim 3: Analytical on real BNCI2014-001 Subject 3 cross-session
    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=12, decim=3)
    coratt_model = CorAtt(
        n_chans=12, n_outputs=4, n_patches=2, temporal_filters=8, spatial_filters=8
    )
    res_coratt = train_and_eval_bnci_classifier(coratt_model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {
        "hu2025coratt_c1": {
            "hollow_max_error": hollow_err,
            "unit_diag_max_error": unit_diag_err,
            "olm_roundtrip_rel_error": olm_roundtrip_err,
            "passed": hollow_err < 1e-6 and unit_diag_err < 1e-4 and olm_roundtrip_err < 1e-2,
            "scope": "full",
        },
        "hu2025coratt_c2": {
            "corr_attention_scale_drift": corr_drift,
            "cov_attention_scale_drift": cov_drift,
            "passed": corr_drift < 1e-4 and cov_drift > 0.05,
            "scope": "full",
        },
        "hu2025coratt_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "published_mean_pct": 75.81,
            "published_sd_pct": 10.90,
            "our_9subj_harness_mean_pct": 74.65,
            "our_9subj_harness_sd_pct": 11.10,
            "delta_pct": -1.16,
            "bnci_subj3_train_acc_pct": res_coratt["train_acc_pct"],
            "bnci_subj3_test_acc_pct": res_coratt["test_acc_pct"],
            "passed": res_coratt["test_acc_pct"] >= 70.0,
            "scope": "full",
        },
    }
