Generalized Bures-Wasserstein Self-Attention Reduces Backward Gradient Explosion on Ill-Conditioned Covariances

Paper: Towards Robust EEG Decoding Based on Riemannian Self-Attention (KDD 2026) · Authors: Tao Zhou, Rui Wang, Ziheng Chen, Xiao-Jun Wu · Geometry: Generalized Bures-Wasserstein Geometry (M, theta) with Positive Curvature

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr5-gbwatt

Closed-Loop Empirical Audit & MOABB / spd-bench Harness Comparison

Why do Log-Euclidean manifold attention layers suffer from gradient amplification when short-window EEG patch covariances have small eigenvalues? To test whether positive-curvature Generalized Bures-Wasserstein (GBW) geometry stabilizes attention gradients, we audit Lucas Heck's GBWAttention and GBWAtt implementation against Log-Euclidean AttentionManifold. First, GBWAttention(6, 5, power=1.5) preserves strict positive definiteness for both the output patch sequence (lambda_min = 0.608) and the learnable reference metric M (lambda_min = 1.00; Panel A, Claim C1). Second, on severely ill-conditioned SPD patch sequences (kappa = 10^6), GBWAttention cuts the backward input gradient norm by 2.44x relative to Log-Euclidean AttentionManifold with identical Q/K/V weights (975.9 vs. 2382.7; Panel B, Claim C2). Third, on real cross-session BNCI2014-001, GBWAtt reaches 70.83% on Subject 3 and 75.10 +/- 11.20% across 9 subjects (vs. 76.42 +/- 10.80% published; Panel C, Claim C3). Overall, these results show that power-deformed Bures-Wasserstein charts avoid the 1/lambda derivative singularity of matrix logarithms.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Pan et al. (2022) compute patch distances and barycenters in the Log-Euclidean domain; whereas MAtt relies on matrix logarithms whose derivatives scale as 1/lambda_min, GBWAtt maps patches through the power-1/(2p) GBW chart.
Primary Failure ModeVery small power parameters (p < 0.25) reintroduce high-power matrix products during inverse chart reconstruction X = (M^{1/2p} (I + U) M^{1/2p})^{2p}.
Silent Diagnostic RiskLeaving the reference matrix M unconstrained without an SPD parametrization allows gradient steps to push M outside the positive definite cone.
Practitioner RecommendationUse power p in [1.0, 1.5] with parametrization of M via SymmetricPositiveDefinite and 1-step closed-form BW barycenter aggregation.

def verify_zhou2026gbwatt() -> dict[str, dict[str, Any]]:
    from spd_learn.models import GBWAtt
    from spd_learn.modules import AttentionManifold, GBWAttention

    X_seq = make_spd((3, 4), 6, cond=12.0, dtype=torch.float32)
    gbw_att = GBWAttention(in_features=6, out_features=5, power=1.5)
    out = gbw_att(X_seq)
    min_eig_out = float(torch.linalg.eigvalsh(out).min().item())
    min_eig_ref = float(torch.linalg.eigvalsh(gbw_att.reference).min().item())

    X_ill = make_spd((4, 4), 6, cond=1e6, dtype=torch.float32).requires_grad_(True)
    loss_gbw = gbw_att(X_ill).sum()
    loss_gbw.backward()
    gbw_grad_norm = float(torch.linalg.norm(X_ill.grad).item())

    X_ill_lem = X_ill.detach().clone().requires_grad_(True)
    lem_att = AttentionManifold(in_features=6, out_features=5)
    with torch.no_grad():
        lem_att.q_trans.weight = gbw_att.q_trans.weight.clone()
        lem_att.k_trans.weight = gbw_att.k_trans.weight.clone()
        lem_att.v_trans.weight = gbw_att.v_trans.weight.clone()
    loss_lem = lem_att(X_ill_lem).sum()
    loss_lem.backward()
    lem_grad_norm = float(torch.linalg.norm(X_ill_lem.grad).item())

    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=22, decim=3)
    model = GBWAtt(
        n_chans=22,
        n_outputs=4,
        n_patches=2,
        temporal_out_channels=10,
        attention_out_features=8,
        power=1.5,
    )
    res = train_and_eval_bnci_classifier(model, X_tr, y_tr, X_te, y_te, epochs=25, lr=8e-3)

    return {

Paper Abstract

Existing manifold attention decoders such as MAtt rely on Log-Euclidean geometry, where logarithmic eigenvalue compression amplifies noise in small eigenvalues of ill-conditioned EEG covariance matrices. We propose GBWAtt based on Generalized (2theta, M)-Bures-Wasserstein geometry with a learnable SPD reference matrix M and power deformation theta, achieving closed-form Wasserstein barycentric attention aggregation and stable gradients on ill-conditioned spectra.
