Deep-Dive Gap Analysis, Failure Modes & Practitioner Guidance

Dataloader & Preprocessing DiffOn Sleep-EDFX and SEED, paper uses custom 30s hypnogram and 4s DE-feature windows; spd-bench standardizes EEG channel picks and trace-regularized patch covariances.
Architecture & Optimizer Diffspd_learn parameterizes the reference metric M = L L^T + εI via Cholesky factor L in GBWAttention, keeping gradient norms 2.5× lower than Log-Euclidean attention at κ = 10610^{6}106.
Where It Struggles / DivergesRequires 3 matrix square-root evaluations per forward pass (M^{-1/2}, (M^{-1/2} X M^{-1/2})^{1/2}); sensitive to batch size < 8 when learning M jointly with Q/K/V.
Primary Mathematical Failure ModeVery small power parameters (p < 0.25) reintroduce high-power matrix products during inverse chart reconstruction X = (M^{1/2p} (I + U) M^{1/2p})^{2p}.
Silent Diagnostic RiskLeaving the reference matrix M unconstrained without an SPD parametrization allows gradient steps to push M outside the positive definite cone.
Practitioner RecommendationUse power p in [1.0, 1.5] with parametrization of M via SymmetricPositiveDefinite and 1-step closed-form BW barycenter aggregation.
