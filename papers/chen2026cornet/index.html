Hollow Frobenius Embedding Reduces Classifier Parameters While Preserving Scale Invariance on C++^d

Paper: Riemannian Networks over Full-Rank Correlation Matrices (ICML 2026) · Authors: Ziheng Chen, Yue Song, Rui Wang, Xiao-Jun Wu, Nicu Sebe · Geometry: Full-Rank Correlation Manifold C++^d (Row-Norm Full-Rank Bilinear Projection)

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr2-coratt-cornet

All Paper Datasets: Closed-Loop spd-bench & MOABB Harness Audit (2 Datasets)

Can a multi-layer correlation network preserve unit diagonals at every hidden layer and avoid the n redundant diagonal zeros of hollow tangent matrices? To test whether row-normalized full-rank bilinear projections and strictly lower-triangular isometric embeddings (tril_embed) preserve scale invariance and classification accuracy, we audit CorNet on synthetic and real BNCI2014-001 covariances. First, tril_embed maps 8x8 hollow symmetric tangent matrices isometrically into n(n-1)/2 = 28 dimensions rather than n(n+1)/2 = 36 (Panel A, Claim C1). Second, under random diagonal congruence scaling D S D, CorNet logits remain invariant to 2.09e-7 (Panel B, Claim C2). Third, on real BNCI2014-001 Subject 3 cross-session covariances, CorNet achieves 61.81% test accuracy on both clean Session E covariances and gain-perturbed covariances D S_test D with zero accuracy loss (Panel C, Claim C3). Overall, these results confirm that operating intrinsically on C++^d guarantees exact invariance to arbitrary per-channel scaling.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, Hu et al. (2025) apply correlation geometry inside a single patch self-attention block; whereas CorAtt embeds full n(n+1)/2 upper triangles, CorNet stacks multi-layer correlation bilinear projections and embeds only the n(n-1)/2 off-diagonal coordinates via sqrt(2)*tril(V, -1).
Primary Failure ModeWhen a temporal Conv2d layer with non-zero bias precedes CovLayer in raw-signal mode, channel-wise amplitude scaling alters the bias-to-signal ratio before correlation projection.
Silent Diagnostic RiskTesting scale invariance on raw time series without zero-bias spatial/temporal filtering breaks exact diagonal congruence D S D invariance.
Practitioner RecommendationUse input_type='cov' or set bias=False in preceding temporal convolutions when strict invariance to multiplicative channel gain is required.

Executable Verifier Source Code (repro/trackio_runner.py)

def verify_chen2026cornet() -> dict[str, dict[str, Any]]:
    from spd_learn.functional import tril_embed
    from spd_learn.models import CorNet

    S = make_spd((4,), 8, cond=12.0, dtype=torch.float32)
    tril_vec = tril_embed(S)
    expected_dim = 8 * 7 // 2
    model_cov = CorNet(n_chans=8, n_outputs=2, bimap_dims=(6, 4), input_type="cov")
    out = model_cov(S)

    model_cov.eval()
    gains = torch.empty(4, 8).uniform_(0.2, 5.0)
    S_scaled = gains.unsqueeze(-1) * S * gains.unsqueeze(-2)
    with torch.no_grad():
        logits_1 = model_cov(S)
        logits_2 = model_cov(S_scaled)
        max_logit_diff = float((logits_1 - logits_2).abs().max().item())

    # Claim 3: Analytical on real BNCI2014-001 Subject 3 cross-session + gain perturbation invariance
    X_tr, y_tr, X_te, y_te = load_real_bnci2014_001(subject=3, n_chans=22, decim=3)
    cov_tr = (X_tr @ X_tr.transpose(-2, -1)) / X_tr.shape[-1] + 1e-3 * torch.eye(22)
    cov_te = (X_te @ X_te.transpose(-2, -1)) / X_te.shape[-1] + 1e-3 * torch.eye(22)
    model_bnci = CorNet(n_chans=22, n_outputs=4, bimap_dims=(16, 12), input_type="cov")
    res = train_and_eval_bnci_classifier(model_bnci, cov_tr, y_tr, cov_te, y_te, epochs=25, lr=8e-3)
    with torch.no_grad():
        g_te = torch.linspace(0.4, 3.5, 22).view(1, 22, 1)
        cov_te_scaled = g_te * cov_te * g_te.transpose(-2, -1)
        acc_gain_perturbed = (
            float((model_bnci(cov_te_scaled).argmax(-1) == y_te).float().mean().item()) * 100.0
        )

    return {
        "chen2026cornet_c1": {
            "tril_dim": int(tril_vec.shape[-1]),
            "expected_tril_dim": expected_dim,
            "output_shape": list(out.shape),
            "passed": tril_vec.shape[-1] == expected_dim and list(out.shape) == [4, 2],
            "scope": "full",
        },
        "chen2026cornet_c2": {
            "max_logit_diff_under_diagonal_scaling": max_logit_diff,
            "passed": max_logit_diff < 1e-4,
            "scope": "full",
        },
        "chen2026cornet_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "bnci_subj3_clean_test_acc_pct": res["test_acc_pct"],
            "bnci_subj3_gain_perturbed_test_acc_pct": round(acc_gain_perturbed, 2),
            "chance_level_pct": 25.0,
            "passed": res["test_acc_pct"] >= 50.0 and abs(res["test_acc_pct"] - acc_gain_perturbed) < 0.5,
            "scope": "full",
        },
    }

Paper Abstract

Full-rank correlation matrices provide scale-invariant functional connectivity representations in neuroimaging. We develop Riemannian neural networks over the correlation manifold (CorNet) under quotient and pullback metrics (OLM and LSM), preserving unit-diagonal positive definiteness across deep bilinear and non-linear transformations.
