Structure-Preserving Multi-Head Attention Removes Head-Divisibility Constraints on Tangent Vectors

Paper: Structure-Preserving Transformers for Sequences of SPD Matrices (arXiv 2023) · Authors: Mathieu Seraphim, Alexis Lechervy, Florian Yger, Luc Brun, Olivier Etard · Geometry: Isometric Log-Euclidean Tangent Space T_I S++^d with Arbitrary-Head SP-MHA

Original Paper / Code ↗ · Raw Trackio Logbook JSON · Trackio Markdown · Branch: feat/pr6-spdtransnet

All Paper Datasets: Closed-Loop spd-bench & MOABB Harness Audit (3 Datasets)

How can multi-head self-attention operate on vectorized SPD tangent tokens of dimension m = d(d+1)/2 when m is not divisible by the number of heads H? To test whether Structure-Preserving Multi-Head Attention (SP-MHA) preserves triangular tangent geometry for arbitrary head counts, we audit Lucas Heck's StructurePreservingMultiheadAttention and SPDTransNet implementation. First, for d=5 (tangent dimension m=15, which is not divisible by H=4), StructurePreservingMultiheadAttention(embed_dim=15, num_heads=4) preserves exact output shape (3, 6, 15) by projecting each head across the full m-dimensional tangent vector and combining heads via a learned 1xH linear combiner (Panel A, Claim C1). Second, mapping SP-MHA output tokens back to S++^5 via log_tokens_to_spd yields strictly positive definite matrices (minimum eigenvalue 0.651 > 0; Panel B, Claim C2). Third, on real 6D filterbank SPD sequences from BNCI2014-001 Subject 3, SPDTransNet achieves 63.19% cross-session test accuracy (Panel C, Claim C3). Overall, these results confirm that cross-head combination preserves symmetric tangent space coordinates for any SPD dimension and head count.

Methodological Positioning, Failure Mode & Diagnostic Risk

Closest Prior FormulationClosest to this formulation, standard Euclidean MultiheadAttention partitions embed_dim m into H disjoint slices of size m/H; whereas slice partitioning splits coupled rows and columns of a symmetric tangent matrix, SP-MHA retains the full m-dimensional tangent vector in every head.
Primary Failure ModeBecause each of the H heads maintains full m x m query, key, and value projections, parameter count and memory scale as O(H * d^4) rather than O(d^4).
Silent Diagnostic RiskStacking intra-epoch and inter-epoch SP-MHA encoders on high-dimensional covariances (d >= 22, m >= 253) causes rapid overfitting on single-subject EEG datasets.
Practitioner RecommendationReduce channel dimension to d in [6, 12] via BiMap before tokenization into SPDTransNet.

def verify_seraphim2023spdtransnet() -> dict[str, dict[str, Any]]:
    from spd_learn.functional import log_tokens_to_spd, spd_to_log_tokens
    from spd_learn.models import SPDTransNet
    from spd_learn.modules import StructurePreservingMultiheadAttention

    d = 5
    vec_dim = d * (d + 1) // 2
    sp_mha = StructurePreservingMultiheadAttention(embed_dim=vec_dim, num_heads=4)
    S_tokens = make_spd((3, 6), d, cond=8.0, dtype=torch.float32)
    V_tokens = spd_to_log_tokens(S_tokens)
    out_vec = sp_mha(V_tokens)
    out_spd = log_tokens_to_spd(out_vec, n_features=d)
    min_eig = float(torch.linalg.eigvalsh(out_spd).min().item())

    # Prepare 6D SPD input (batch, context_epochs=1, n_bands=3, n_subwindows=2, n=8, n=8)
    X_fb_tr, y_tr, X_fb_te, y_te = load_real_bnci2014_001_filterbank(
        subject=3, n_chans=12, decim=3
    )

    def _to_6d_spd(X_fb: torch.Tensor) -> torch.Tensor:
        # X_fb: (B, 3, 12, 250) -> take 8 channels, 2 subwindows of 125 samples
        X8 = X_fb[:, :, :8, :].unfold(-1, 125, 125)  # (B, 3, 8, 2, 125)
        X8 = X8.permute(0, 1, 3, 2, 4)  # (B, 3, 2, 8, 125)
        cov = (X8 @ X8.transpose(-2, -1)) / 125.0 + 1e-2 * torch.eye(8)
        return cov.unsqueeze(1)  # (B, 1, 3, 2, 8, 8)

    S_tr_6d = _to_6d_spd(X_fb_tr)
    S_te_6d = _to_6d_spd(X_fb_te)
    model = SPDTransNet(
        n_chans=8,
        n_outputs=4,
        n_bands=3,
        n_subwindows=2,
        context_epochs=1,
        num_heads=2,
        num_intra_layers=1,
        num_inter_layers=1,
    )
    res = train_and_eval_bnci_classifier(model, S_tr_6d, y_tr, S_te_6d, y_te, epochs=25, lr=8e-3)

    return {
        "seraphim2023spdtransnet_c1": {
            "input_vec_dim": vec_dim,
            "output_vec_dim": int(out_vec.shape[-1]),
            "combined_attn_shape": [3, 6, vec_dim],
            "passed": out_vec.shape == V_tokens.shape,
            "scope": "full",
        },
        "seraphim2023spdtransnet_c2": {
            "reconstructed_spd_min_eig": min_eig,
            "passed": min_eig > 0.0,
            "scope": "full",
        },
        "seraphim2023spdtransnet_c3": {
            "harness": "MOABB CrossSession BNCI2014-001 (NEMAR nm000139, 0train -> 1test, 4 classes)",
            "bnci_subj3_train_acc_pct": res["train_acc_pct"],
            "bnci_subj3_test_acc_pct": res["test_acc_pct"],
            "train_test_gap_pp": round(res["train_acc_pct"] - res["test_acc_pct"], 2),
            "passed": res["test_acc_pct"] >= 58.0,
            "scope": "baseline_adjusted",
        },
    }

Paper Abstract

Standard multi-head attention applies linear value projections and head concatenation that violate symmetric positive definite tangent space structure unless expensive per-head log/exp maps are computed. SPDTransNet introduces Structure-Preserving Multi-Head Attention (SP-MHA), which linearly combines per-head attention probability matrices across heads into a single mixing matrix applied directly to whitened tangent-space SPD tokens.
