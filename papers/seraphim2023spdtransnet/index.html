Original Authors' Code / Protocol Root Cause

TWO AUTHOR FLAWS in MathieuSeraphim/SPDTransNet: (1) Whitens SPD matrices using the **entire recording (including test epochs)** before splitting; (2) Has **zero spatial BiMap layers**, feeding raw d(d+1)/2=253d(d+1)/2 = 253d(d+1)/2=253-dim tangent vectors into two non-residual sinusoidal MLPs and a **450K-parameter classifier** that massively overfits 288-trial EEG sessions.

Our spd_learn Code / Harness Fix

Replaced full-recording whitening with strictly **inductive training-set whitening** (Mtrain−1/2CMtrain−1/2M_{\text{train}}^{-1/2} C M_{\text{train}}^{-1/2}Mtrain−1/2​CMtrain−1/2​ fitted on Xtr only) and identity-initialized MLPs. On Voyager BNCI2014-001, SPDTransNet reaches **65.47±16.2765.47 \pm 16.2765.47±16.27%** (final 64.16%), but ranks **#22 out of 24 models (62.61% mean)** across the 10 MOABB datasets due to lacking spatial BiMap filtering.

Dataloader & Preprocessing Diff

Original sleep-staging code whitens 21-epoch sequences across whole overnight recordings (Sleep-EDFX, MASS-SS3); Voyager enforces causal training-only whitening.

Where It Fails / Struggles

Without a spatial BiMap bottleneck, the 450K-param classifier overfits high-channel datasets (Cho2017: 58.96%, Lee2019-MI: 58.58%, Schirrmeister2017: 51.14%).

Paper Abstract & Core Formulation

Standard multi-head attention applies linear value projections and head concatenation that violate symmetric positive definite tangent space structure unless expensive per-head log/exp maps are computed. SPDTransNet introduces Structure-Preserving Multi-Head Attention (SP-MHA), which linearly combines per-head attention probability matrices across heads into a single mixing matrix applied directly to whitened tangent-space SPD tokens.

Deep-Dive Root-Cause Attribution (Original Authors' Code vs. Our Code), Failure Modes & Practitioner Guidance

Original Authors' Code / Protocol Root CauseTWO AUTHOR FLAWS in MathieuSeraphim/SPDTransNet: (1) Whitens SPD matrices using the **entire recording (including test epochs)** before splitting; (2) Has **zero spatial BiMap layers**, feeding raw d(d+1)/2=253d(d+1)/2 = 253d(d+1)/2=253-dim tangent vectors into two non-residual sinusoidal MLPs and a **450K-parameter classifier** that massively overfits 288-trial EEG sessions.
Our spd_learn Code / Harness Fix AppliedReplaced full-recording whitening with strictly **inductive training-set whitening** (Mtrain−1/2CMtrain−1/2M_{\text{train}}^{-1/2} C M_{\text{train}}^{-1/2}Mtrain−1/2​CMtrain−1/2​ fitted on Xtr only) and identity-initialized MLPs. On Voyager BNCI2014-001, SPDTransNet reaches **65.47±16.2765.47 \pm 16.2765.47±16.27%** (final 64.16%), but ranks **#22 out of 24 models (62.61% mean)** across the 10 MOABB datasets due to lacking spatial BiMap filtering.
Dataloader & Preprocessing DiffOriginal sleep-staging code whitens 21-epoch sequences across whole overnight recordings (Sleep-EDFX, MASS-SS3); Voyager enforces causal training-only whitening.
Architecture & Optimizer Diffspd_learn implements SPMultiHeadAttention (SP-MHA) via triangular tril_to_sym re-projection with inductive training-set whitening.
Where It Struggles / DivergesWithout a spatial BiMap bottleneck, the 450K-param classifier overfits high-channel datasets (Cho2017: 58.96%, Lee2019-MI: 58.58%, Schirrmeister2017: 51.14%).
Primary Mathematical Failure ModeBecause each of the H heads maintains full m x m query, key, and value projections, parameter count and memory scale as O(H * d^4) rather than O(d^4).
Silent Diagnostic RiskStacking intra-epoch and inter-epoch SP-MHA encoders on high-dimensional covariances (d >= 22, m >= 253) causes rapid overfitting on single-subject EEG datasets.
Practitioner RecommendationReduce channel dimension to d in [6, 12] via BiMap before tokenization into SPDTransNet.
