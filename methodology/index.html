2. Deconstructing the ICML 2026 Open Reproductions Schema

Instead of treating a paper as a monolithic pass or fail entity, our pipeline mirrors the four canonical files of the ICML-2026-agent-repro/challenge dataset:

  • repro/papers.json: Canonical index mapping each paper ID (9 foundational models from spd_learn plus 18 recent architectures from 2023 to 2026) to its venue, DOI or arXiv URL, isolated worktree branch, and target classes.
  • repro/abstracts.json: Key-value store of the raw paper abstracts used for claim grounding.
  • repro/claims.json: Flat index of all 81 discrete, falsifiable assertions with explicit quantitative thresholds.
  • repro/challenge.json: Master state file tracking the anchor claims and their current judge verdict (Verified, Baseline-Adjusted, Falsified, or Inconclusive).

4. The 3-Column Visual Reproducibility & Dataloader Gap Taxonomy

Every paper, figure, and table in the registry is audited across three columns (1 · Original Figure | 2 · Our Replicability | 3 · The Gap & Pipeline Differences) and classified into one of three empirical replication regimes:

✓ TIGHT REPLICATION (18 PAPERS) |Δ| ≤ 1.75%

Mechanism: Standard single-band covariance or skeletal/radar SPD benchmarks where the published paper uses standard epoching and inductive BatchNorm statistics.

Representative Models: Phase-SPDNet (−0.23%-0.23\%−0.23%), SPDNet (−0.4%-0.4\%−0.4%), SPDNetBN (−0.5%-0.5\%−0.5%), MAtt (−0.3%-0.3\%−0.3%), CorAtt (−0.3%-0.3\%−0.3%), CorNet (−0.4%-0.4\%−0.4%), RieTrans (−0.5%-0.5\%−0.5%), GBWAtt (−0.5%-0.5\%−0.5%), ARMAGNAC (0.0%0.0\%0.0%), ALEM (−0.4%-0.4\%−0.4%).

◐ DATALOADER / PROTOCOL GAP (7 PAPERS) 1.75% < |Δ| ≤ 4.5%

Mechanism: The Riemannian operator matches to machine precision (10−1510^{-15}10−15), but the paper's preprocessing or dataloader differs from standardized causal MOABB evaluation:

  • GREEN (−1.4%-1.4\%−1.4%): Published pipeline uses custom MNE-BIDS + autoreject trial cleaning and subject-wise high-pass standardization vs. raw MOABB epochs.
  • TSMNet (−1.8%-1.8\%−1.8%): Published pipeline uses transductive test-session domain batch statistics vs. causal inductive evaluation.
  • Tensor-CSPNet (−1.8%-1.8\%−1.8%) & Graph-CSPNet (−2.0%-2.0\%−2.0%): 9-band filterbank & multi-window graph topology vs. single-band MOABB harness.
! BASELINE / REGIME SHIFT (2 PAPERS) |Δ| > 4.5%

Mechanism: Either the published baseline was under-tuned or the architecture over-parameterizes small-sample EEG regimes:

  • LieBN (+3.6%+3.6\%+3.6% baseline gain / Karcher divergence): Properly tuned SPDNetBN matches LieBN on HDM05, and 1-step Karcher mean diverges at κ(X)=106\kappa(X)=10^6κ(X)=106.
  • EEGSPDNet (−6.7%-6.7\%−6.7% on 288-trial sessions): Deep channel-specific convolution (88×8888\times 8888×88 covariance) over-parameterizes small cross-session motor imagery splits without heavy regularization.

5. Reproducing Everything on the Voyager Cluster in 3 Commands

All 27 Trackio logbooks, 81 claim verifications, and the static Encore site are regenerated deterministically on the Voyager cluster:

# 1. Run all 81 claim verifiers on Voyager and emit Trackio logbooks (repro/logbooks/*_logbook.{json,md})
python -m repro.trackio_runner run --all

# 2. Run the untrusted-narrative automated Logbook Judge and emit verdicts.json + LEADERBOARD.md
python -m repro.judge

# 3. Rebuild this static Encore Science registry & 81-panel SVG visual atlas
python -m repro.build_encore_site
