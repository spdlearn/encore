2. Deconstructing the ICML 2026 Open Reproductions Schema

Instead of treating a paper as a monolithic pass or fail entity, our pipeline mirrors the four canonical files of the ICML-2026-agent-repro/challenge dataset:

  • repro/papers.json: Canonical index mapping each paper ID (8 foundational models from spd_learn plus 18 recent architectures from 2023 to 2026) to its venue, DOI or arXiv URL, isolated worktree branch, and target classes.
  • repro/abstracts.json: Key-value store of the raw paper abstracts used for claim grounding.
  • repro/claims.json: Flat index of all 78 discrete, falsifiable assertions with explicit quantitative thresholds.
  • repro/challenge.json: Master state file tracking the anchor claims and their current judge verdict (Verified, Baseline-Adjusted, Falsified, or Inconclusive).

3. Translating to Neuroinformatics: The 3-Tier Claim Taxonomy

Every paper in spd_learn is audited across three orthogonal dimensions modeled on the NEMAR BIDS and MOABB benchmarking protocols:

  • Tier 1 (Structural Identity, C1): Tests exact differential-geometric identities ($\text{Exp}_P(\text{Log}_P(X)) = X$ to $10^{-15}$, hollow tangent diagonals $\text{diag}(\Phi(C)) = 0$, $\mathcal{H} \#_0 \mathcal{A} = \mathcal{H}$, and positive-definite cone closure $\lambda_{\min}(Y) > 0$).
  • Tier 2 (Signal & Conditioning Regime, C2): Tests behavior under neurophysiological edge conditions: ill-conditioned covariances ($\kappa(X) = 10^6$), random per-electrode impedance scaling ($D S D$), temporal window jitter, and small-sample attention entropy saturation.
  • Tier 3 (Analytical MOABB & spd-bench Harness, C3): Evaluates cross-session motor imagery decoding on MOABB BNCI2014-001 (NEMAR nm000139, Session 0 train $\to$ Session 1 test) and skeletal action recognition on spd-bench HDM05.

4. Reproducing Everything on the Voyager Cluster in 3 Commands

All 26 Trackio logbooks, 78 claim verifications, and the static Encore site are regenerated deterministically on the Voyager cluster:

# 1. Run all 78 claim verifiers on Voyager and emit Trackio logbooks (repro/logbooks/*_logbook.{json,md})
python -m repro.trackio_runner run --all

# 2. Run the untrusted-narrative automated Logbook Judge and emit verdicts.json + LEADERBOARD.md
python -m repro.judge

# 3. Rebuild this static Encore Science registry & 78-panel SVG visual atlas
python -m repro.build_encore_site
