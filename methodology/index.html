2. Deconstructing the ICML 2026 Open Reproductions Schema

Instead of treating a paper as a monolithic pass/fail entity, our pipeline mirrors the four canonical files of the ICML-2026-agent-repro/challenge dataset:

  • repro/papers.json: Canonical index mapping each paper ID (e.g., zhou2026gbwatt, gallet2026armagnac) to its venue, DOI/arXiv URL, isolated worktree branch, and target spd_learn classes.
  • repro/abstracts.json: Key-value store of the raw paper abstracts used for claim grounding.
  • repro/claims.json: Flat index of all 54 discrete, falsifiable assertions with explicit quantitative thresholds.
  • repro/challenge.json: Master state file tracking the anchor claims and their current judge verdict (VERIFIED, TOY, FALSIFIED, or INCONCLUSIVE).

3. Translating to Neuroinformatics: The 3-Tier Claim Taxonomy

Every paper in spd_learn is audited across three orthogonal epistemological dimensions inspired by the NEMAR BIDS / MNE-BIDS-Pipeline audit architecture:

  • Tier 1 — Structural & Mathematical Identity (C1, Full Scope = 2 pts): Tests exact differential-geometric identities (e.g., $\text{Exp}_P(\text{Log}_P(X)) = X$ to $10^{-15}$, hollow tangent diagonals $\text{diag}(\Phi(C)) = 0$, $\mathcal{H} \#_0 \mathcal{A} = \mathcal{H}$, and positive-definite cone closure $\lambda_{\min}(Y) > 0$).
  • Tier 2 — Signal & Conditioning Regime (C2, Full Scope = 2 pts): Tests behavior under neurophysiological edge conditions: severely ill-conditioned covariances ($\kappa(X) = 10^6$), random per-electrode impedance/gain perturbations ($D S D$), temporal window jitter, and small-sample attention entropy saturation.
  • Tier 3 — Analytical EEG Decoding (C3, Toy Scope = 1 pt): End-to-end supervised or self-supervised optimization on multi-channel oscillatory EEG trials, verifying loss convergence and held-out test accuracy $\ge 75\%$.

4. Reproducing Everything Locally in 2 Commands

All 18 Trackio logbooks, 54 claim verifications, and the static Encore site can be regenerated deterministically from the unified worktree:

# 1. Run all 54 claim verifiers and emit Trackio logbooks (repro/logbooks/*_logbook.{json,md})
python -m repro.trackio_runner run --all

# 2. Run the untrusted-narrative automated Logbook Judge and emit verdicts.json + LEADERBOARD.md
python -m repro.judge

# 3. Rebuild this static Encore Science registry & 54-panel SVG visual atlas
python -m repro.build_encore_site
