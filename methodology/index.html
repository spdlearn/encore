2. Deconstructing the ICML 2026 Open Reproductions Schema

Instead of treating a paper as a monolithic pass or fail entity, our pipeline mirrors the four canonical files of the ICML-2026-agent-repro/challenge dataset:

  • repro/papers.json: Canonical index mapping each paper ID (9 foundational models from spd_learn plus 18 recent architectures from 2023 to 2026) to its venue, DOI or arXiv URL, isolated worktree branch, and target classes.
  • repro/abstracts.json: Key-value store of the raw paper abstracts used for claim grounding.
  • repro/claims.json: Flat index of all 81 discrete, falsifiable assertions with explicit quantitative thresholds.
  • repro/challenge.json: Master state file tracking the anchor claims and their current judge verdict (Verified, Baseline-Adjusted, Falsified, or Inconclusive).

3. Translating to Neuroinformatics: The 3-Tier Claim Taxonomy

5. Reproducing Everything on the Voyager Cluster in 3 Commands

All 27 Trackio logbooks, 81 claim verifications, and the static Encore site are regenerated deterministically on the Voyager cluster:

# 1. Run all 81 claim verifiers on Voyager and emit Trackio logbooks (repro/logbooks/*_logbook.{json,md})
python -m repro.trackio_runner run --all

# 2. Run the untrusted-narrative automated Logbook Judge and emit verdicts.json + LEADERBOARD.md
python -m repro.judge

# 3. Rebuild this static Encore Science registry & 81-panel SVG visual atlas
python -m repro.build_encore_site
